# DeepSeek 用量信息查询

- 日期：2026-07-31
- 类型：feature
- 关联文件：src/shared/subscriptionTypes.ts、src/core/subscriptions/types.ts、src/core/subscriptions/DeepSeekProvider.ts、src/core/subscriptions/SubscriptionManager.ts、electron/main.ts、electron/preload.ts、src/renderer/vite-env.d.ts、src/renderer/pages/SubscriptionsPage.tsx、src/renderer/styles.css

## 变更摘要

- "其他订阅"弹窗在余额查询基础上补充 DeepSeek 用量信息查询，调用平台控制台内部接口 `GET https://platform.deepseek.com/api/v0/usage/amount?month=&year=`（未公开接口，需网页登录的用量 Token 鉴权，与 API Key 是两套凭证）
- 新增凭据种类 `SubscriptionCredentialKind`（`apiKey` / `usageToken`），`saveKey/clearKey` 及 IPC `subscription-save-key`/`subscription-clear-key` 增加 kind 参数（默认 apiKey，向后兼容）；DeepSeek 用量 Token 存于 CredentialVault 账户 `deepseek-usage-token`
- `SubscriptionProvider` 接口新增可选 `fetchUsage(query)` 与 `usageCredentialAccount`；`SubscriptionProviderMeta` 新增 `usageSupported`/`usageConfigured`，不支持用量的订阅源 UI 自动隐藏相关区块
- `DeepSeekProvider.fetchUsage`：携带浏览器 UA 与 `x-app-version` 请求头；防御式解析 `biz_data.total`（PROMPT_CACHE_HIT_TOKEN / PROMPT_CACHE_MISS_TOKEN / RESPONSE_TOKEN / REQUEST，未知 token 类指标计入总量），汇总各模型总 Token、输出 Token、请求数与缓存命中率；401/403 提示 Token 过期需重新登录，结构无法识别时提示内部接口可能已变动
- 新增 IPC `subscription-fetch-usage`（主进程校验月份 1-12、年份 2000-2100），preload 与 vite-env.d.ts 暴露 `fetchSubscriptionUsage`
- 弹窗页面新增"用量 Token 配置"区（密码框、保存/清除、获取方式说明：登录 platform.deepseek.com 后控制台执行 `JSON.parse(localStorage.userToken).value`）与"用量信息查询"区（月份选择器默认当月、按模型用量表格、总 Token/总请求数汇总、内部接口不稳定提示）
- 用量查询不纳入 Poller 自动轮询，仅弹窗内手动触发

## 影响范围

- "其他订阅"弹窗（新增两个区块，余额查询功能不变）
- 订阅核心层与 IPC（save/clear 增加可选 kind 参数，旧调用默认 apiKey 行为不变）
- 依赖 DeepSeek 平台未公开内部接口，接口变动时用量查询可能失效（已做防御式解析与友好报错，余额查询不受影响）

## 验证

- `npm run typecheck` 通过（electron 与 renderer 两套 tsconfig）
- `npm run build` 通过，subscriptions chunk 正常产出
- 人工验证（待用户执行）：弹窗保存用量 Token → 选择月份查询展示按模型用量；未配置 Token 时查询按钮禁用并提示；过期 Token 返回 401 提示重新登录获取
