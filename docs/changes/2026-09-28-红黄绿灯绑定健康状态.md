# 红黄绿灯绑定健康状态

- 日期：2026-09-28
- 类型：feature
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css、README.md

## 变更摘要

弹窗 header 的三色灯此前是**零 props 的纯装饰动画**（`TrafficLights()` 无参数，`styles.css` 写死 2.7s 错相位无限循环），README 亦明确记载「与健康状态 / 用量数据完全解耦」。一个 3 槽位的严重度信号灯不承载任何严重度语义，属于纯装饰冗余。

本次将三色灯绑定到**连接/刷新健康状态**，使点亮的颜色与动效真实反映取数链路状况。

### 候选信号评估

| 信号 | 位置 | 档位 | 结论 |
|---|---|---|---|
| 连接/刷新健康 | `healthColor()` App.tsx:57 + `PollerState` | 正常/缓存/退避/暂停/无数据/刷新中 | **采纳**，语义与红黄绿天然同构 |
| 配额水位 | `getPercentStatusLevel()` format.ts:241 | ≥85 danger / ≥60 warn / ok / unknown | 弃用，与悬浮球环语义重复；且「链路正常但额度超标」时无法区分红黄绿说的是链路还是额度 |
| 刷新调度 | `PollerState.nextRefreshAt` / `backoffMs` | 4 档 + 时间维 | 弃用，三色灯装不下 |
| 数据源 `source-tag` | `official` / `cookie` | 2 档 | 弃用，档位不够 |

### 状态映射（`trafficSignal()`）

| 信号 | 灯态 | 动效 |
|---|---|---|
| `status === 'backoff'` | 红 | 快闪 0.7s |
| `backoff` 且 `failureCount ≥ 2` | 红 | 慢闪 1.8s |
| `snapshot.stale`（非 backoff） | 黄 | 呼吸 1.4s |
| `isRefreshing` | 绿 | 呼吸 1.4s |
| 正常 running | 绿 | 常亮 |
| `status === 'paused'` / 无 snapshot | 全灭 | 无 |

`off` 档（已暂停 / 无数据）用**三灯全灭**表达空闲态，避免「全灭 = 挂了」的误读，同时不需要引入第四盏蓝灯。

### backoff 优先级调整（重要）

原 `healthColor()` / `healthLabel()` 把 `stale` 排在 `backoff` 之前，二者合并为同一黄色档。本次**将 backoff 提到 stale 之前并单独用红色**：

- `core/poller.ts` 在刷新抛异常时才进入 `backoff`，即真实的请求失败 → 红色
- `snapshot.stale` 是「取数失败但仍在用上次缓存服务」→ 黄色降级

原顺序会让真实故障显示成黄色警告，掩盖故障。调整后语义为：**红 = 故障，黄 = 降级**。

### 一致性连带修改：悬浮球环

`health` 变量同时驱动悬浮球环配色（`.floating-ball__orb--health-*`，App.tsx:418），因此本次同步新增 `.floating-ball__orb--health-red` 档（绯红 → 玫瑰 → 浅金调），使**球环与三色灯对同一 backoff 状态显示同一颜色**。若不做此修改，同一故障下会出现「球环黄、灯红」的自相矛盾。

> 这是超出「三色灯」字面范围的连带修改，用于保证同一状态在两个指示器上不冲突；如需保留球环原黄色，可回退 `healthColor()` 的 backoff 分支并删除红档样式。

### 移除 health-pill

概览卡片 `dashboard-summary__meta` 中的 `health-pill` 标签已删除，同步清理 `.health-pill*` 样式（5 条规则）。

- 原状态信息藏在内层 Tab 且被 `{snapshot && ...}` 守卫，无数据时不可见
- 绑定后三色灯在 header 常驻，成为状态唯一呈现位置
- 精确文案由三色灯的 `title` + `aria-label` 承载

### 样式实现

- 删除 `@keyframes trafficLightCycle{R,Y,G}` 三组循环关键帧及 `animation-delay` 错相位
- 通电色抽为 CSS 变量 `--lamp-color` / `--lamp-glow`，供各档复用
- 新增 `.traffic-lights--{off|ok|fetching|warn|error}` 容器状态类，`.traffic-lights--slow` 控制慢闪
- 动效只作用于 `transform` + `filter`，不逐帧重绘 `box-shadow`
- `prefers-reduced-motion: reduce` 下关闭呼吸/闪烁（`animation: none` + `filter: none`），**保留当前状态的静态点亮色**——与旧版「一律熄灭」不同，减少动效用户仍可获知状态

## 可访问性

- 容器 `role="status"`，`aria-label` 携带精确状态（如「状态指示灯：退避中」）
- 同时提供 `title` 供鼠标 hover 查看
- 三颗灯本身保持 `aria-hidden`，避免冗余朗读

## 影响范围

- 弹窗 header 三色灯
- 概览卡片 meta 行（移除 health-pill）
- 悬浮球环 backoff 配色由黄改红
- 不改数据流、不改刷新/设置/收起按钮、不改窗口尺寸与拖拽行为
