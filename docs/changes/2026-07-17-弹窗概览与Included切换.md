# 弹窗概览与 Included 切换

- 日期：2026-07-17
- 类型：feature
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css、electron/main.ts

## 变更摘要

- 弹窗默认只展示用量概览（总消耗 + 明细卡片 + 状态提示），去除整面板纵向滚动条
- 有 Included Usage 数据时，底部提供「概览 / Included」分段切换
- Included 视图仅在表格区域内滚动，概览视图保持无滚动

## 补充（同日）

- 展开窗体高度 448→592，面板随窗口自适应高度
- 概览态收紧 summary / 明细卡片间距，确保 4 张卡片完整可见
- 移除「正在拉取最新数据」提示条；明细改为 2×2 紧凑网格（百分比与 token 同列）
- 展开窗体高度微调为 520，配合紧凑布局完整展示概览
- 明细卡片改为标签独占一行，避免「今日 First-party models」等长文案被截断
- 展开窗体宽度 300→340，面板随窗口自适应；Included 模型名允许换行完整展示

## 影响范围

- 展开弹窗默认交互与可视高度
- Included Usage 由同屏堆叠改为分段查看

## 验证

- `npm run typecheck`
- 展开弹窗默认无纵向滚动条，可见总消耗与全部 4 张明细卡片
- 有 Included 数据时出现底部分段；切换后可查看表，切回概览无滚动
- 无 Included 数据时不出现分段
- 刷新中 banner 与电流边框仍正常
