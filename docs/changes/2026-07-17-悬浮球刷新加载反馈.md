# 悬浮球刷新加载反馈

- 日期：2026-07-17
- 类型：feature
- 关联文件：src/shared/types.ts、src/core/poller.ts、src/renderer/App.tsx、src/renderer/styles.css

## 变更摘要

- `PollerState` 新增 `fetching` 字段，拉取开始/结束时由 poller 广播
- 点击刷新后立即显示加载态（本地 pending + poller fetching），覆盖数秒网络延迟
- 刷新图标旋转、按钮禁用、顶部进度条、状态 pill 与「上次刷新」文案同步切换

## 影响范围

- 手动刷新与自动刷新均会触发 fetching 反馈
- 刷新完成或失败后加载态自动消失

## 验证

- `npm run typecheck`
- 点击刷新，确认数秒内面板有可见反馈，数据返回后恢复正常
- 刷新过程中面板不出现横向滚动条

## 补充（同日）

- 顶部进度条由伪元素改为 `overflow: hidden` 容器内动画，面板增加 `overflow-x: hidden`，修复刷新时异常横向滚动条
- 移除「正在拉取最新数据」文字提示条，保留顶部进度条与刷新图标旋转
