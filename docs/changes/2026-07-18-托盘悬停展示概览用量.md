# 托盘悬停展示概览用量

- 日期：2026-07-18
- 类型：feature
- 关联文件：src/shared/format.ts、electron/tray.ts、electron/main.ts

## 变更摘要

- 新增 `formatTrayTooltip`，将快照格式化为多行概览摘要（总消耗、今日/周期 API 与 FP 分项、来源与更新时间）
- 托盘新增 `updateTrayToolTip`，替换固定文案 `Cursor Token Monitor`
- 主进程在启动、轮询快照与手动刷新后同步更新托盘悬停提示；无快照时回退为「暂无数据」

## 影响范围

- Windows 系统托盘图标悬停文字由应用名改为概览用量信息
- 随现有 poller / 手动刷新更新，不额外增加实时轮询

## 验证

- 启动后悬停托盘图标，应看到缓存快照的多行概览
- 手动刷新或等待一轮轮询后，文案随新快照变化
- 无缓存时显示「Cursor Token Monitor · 暂无数据」
- 某分项缺失时对应位置为 `--`
