# 明细 API/FP 分区强化

- 日期：2026-07-21
- 类型：feature
- 关联文件：src/renderer/components/IncludedUsageTable.tsx、src/renderer/styles.css

## 变更摘要

- 明细中 API 与 First-party（FP）仅靠细左边线区分，不易辨认
- 两类改为独立色块分区：API 翠绿底/边框，FP 蓝色底/边框
- 分区头增加实心徽章（`API` / `FP`），用量百分比也跟分区配色
- 模型行保留对应色左边线，嵌在分区容器内

## 影响范围

- 悬浮球弹窗「明细」视图的分类视觉层级

## 验证

- 打开明细：API 与 FP 分区底色、徽章颜色明显不同
- 滚动长列表时两类区块边界清晰
