# 托盘图标模糊优化

- 日期：2026-09-09
- 类型：fix
- 关联文件：electron/iconManager.ts、scripts/create-icon.ps1、src/renderer/pages/SettingsPage.tsx

## 变更摘要

### 根因分析

托盘图标模糊由三层问题叠加导致：

1. **ICO 目录头宽高字段全部为 0（根因）**：`create-icon.ps1` 的 `Save-PngIco` 函数在写入 ICONDIRENTRY 时，width/height 字节硬编码为 `[byte]0`，而 ICO 规范中 0 表示 256×256。虽然 PNG 数据本身是 16/32/48/256 四种尺寸，但目录头全部标记为 256，Windows 只能找到 256 这一个尺寸，小尺寸托盘图标只能从 256 缩放而来 → 模糊。

2. **源图非正方形**：`build/icon.png` 实际尺寸 1536×1024（3:2），直接 resize 到正方形会导致变形。

3. **托盘图标目标尺寸过小**：`loadTrayIcon` 仅 resize 到 16×16，在高 DPI 屏幕（200%/300%）上系统需放大显示 → 进一步模糊。

### 修复内容

- **`scripts/create-icon.ps1`**：
  - `Save-PngIco` 函数新增 `-Sizes` 参数，按 ICO 规范正确写入每个 entry 的 width/height 字节（256 用 0 表示，其余直接写像素值）
  - `$sizes` 数组新增 64 尺寸，ICO 包含 16/32/48/64/256 五种尺寸
- **`electron/iconManager.ts`**：
  - 新增 `cropToSquare`：从原图居中裁剪为正方形后再 resize
  - `loadTrayIcon` 目标尺寸由 16×16 提升至 64×64，确保高 DPI 屏幕清晰
  - `getIconPreviewDataUrl` 同步应用 `cropToSquare`
- **`src/renderer/pages/SettingsPage.tsx`**：
  - 外观分区新增建议尺寸说明：正方形 PNG、256×256 以上、32bit

## 影响范围

- Windows 系统托盘图标显示质量（含高 DPI 屏幕）
- 打包生成的 ICO 文件（需重新运行 `scripts/create-icon.ps1` 后重新打包安装）
- 设置页外观分区文字提示

## 验证

- `npm run typecheck` 通过（electron 与 renderer 两套 tsconfig）
- 重新运行 `scripts/create-icon.ps1` 生成 ICO，验证 5 个 entry 的目录头宽高与 PNG 实际尺寸一致（16/32/48/64/256）
- 人工验证（待用户执行）：启动应用后观察托盘图标清晰度，确认无变形无模糊；重新打包安装后验证 EXE 图标同样清晰
