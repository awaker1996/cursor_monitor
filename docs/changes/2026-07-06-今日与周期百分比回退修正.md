# 今日与周期百分比回退修正

- 日期：2026-07-06
- 类型：fix
- 关联文件：src/core/normalizer.ts

## 变更摘要

- 修正“今日 API / 今日 Auto + Composer”百分比推导逻辑
- 当费用占比推导出现可疑场景（今日费用占比近似 100%，但今日 token 量明显小于周期 token）时，自动回退到 token 占比推导
- 为推导结果增加边界保护，确保结果在 `0` 到 `周期百分比` 之间

## 影响范围

- 避免“今日 API”和“周期 API”错误显示为同一百分比
- 在 Cursor Dashboard 返回历史费用字段不完整时，今日消耗展示更贴近真实趋势

## 验证

- `npm run typecheck` 通过
- 典型场景下：`todayTokens < cycleTokens` 时，今日百分比不再被错误拉平到周期百分比
