# Grok Bot 计入开关

- 日期：2026-09-22
- 类型：feature
- 关联文件：src/shared/types.ts、src/core/normalizer.ts、src/core/providers/ProviderManager.ts、src/core/UsageFlowCache.ts、electron/main.ts、src/renderer/components/SettingsTabContent.tsx、src/renderer/pages/FlowPage.tsx、src/renderer/styles.css、scripts/verify-*.ts

## 变更摘要

- 「其他 → 数据刷新」新增「计入 Grok Bot 用量」开关（默认关闭），控制今日%、模型明细、用量流水是否包含 grok-bot-automation / grok-bot-default
- 周期官方 Cursor Models % 仍使用 API `autoPercentUsed`，不受开关影响
- 切换开关后清空 Cursor 流水缓存并立即刷新用量快照；流水页监听设置变更自动重拉
- 「其他」Tab 顶行卡片改为 `align-items: start`，消除悬浮球卡被网格撑高后的底部留白

## 影响范围

- 悬浮球今日%、Included Usage、订阅模型表、用量流水（Cursor 平台）
- 设置页「数据刷新」卡片文案与布局
