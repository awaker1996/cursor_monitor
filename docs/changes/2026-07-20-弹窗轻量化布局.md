# 弹窗轻量化布局

- 日期：2026-07-20
- 类型：feature
- 关联文件：src/renderer/styles.css、src/renderer/components/IncludedUsageTable.tsx、electron/windows/floatingBall.ts

## 变更摘要

- 概览明细卡片由 2×2 网格改为单列纵向排列
- 未贴边展开窗体宽度 360→300，与贴边 peek 同宽，整体更紧凑
- 明细 API 名称改为自动换行，去除单行跑马灯
- 明细 Tokens / Usage 列宽压缩（52px / 40px），与概览同宽面板对齐

## 补充（同日）

- 概览卡片改为标签、百分比、Token 同行排列，收紧 summary 间距，窗体高度 520→548，修复末卡被底栏遮挡
- 明细由表格改为与概览一致的卡片式单行布局（名称 | Tokens | Usage），分类汇总与模型条目同结构
- 概览卡片固定百分比 / Token 两列宽并右对齐，无 Token 时显示 `0 tokens` 或 `—` 占位，避免各行错位
- 概览卡片布局与总消耗一致：标签 + 百分比同行（百分比靠右）、进度条、Token 另起一行
- 概览 Token 行字号 9→10px（总消耗与明细卡片同步）
- 明细每一项增加鼠标悬浮高亮（120ms 过渡）

## 影响范围

- 悬浮球展开弹窗概览与明细视图布局
- Included Usage 长模型名展示方式

## 验证

- `npm run typecheck`
- 展开弹窗概览：4 张卡片单列完整可见，无横向滚动
- 切换明细：列宽与概览面板一致，长 API 名称可换行
- 贴边 undock 后恢复 300×520 展开尺寸
