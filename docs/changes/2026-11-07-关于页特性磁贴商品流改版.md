# 关于页：特性磁贴改版为商品流式错落网格

- 日期：2026-11-07
- 类型：style, refactor
- 关联文件：`src/renderer/components/ProjectFeaturesCard.tsx`, `src/renderer/styles.css`, `README.md`

## 变更摘要

- 「关于」页的功能要点由「两列扁平行卡」改为「三列商品磁贴」：每张磁贴是「图标 + 标题 + 说明」的竖排卡片，靠列间不同的顶部偏移制造瀑布流般的错落感
- 磁贴视觉升级：左上角品牌渐变高光、径向冷光叠加的卡面、内阴影 + 外投影、悬停上浮 3px 并点亮描边与光晕
- 数据结构不变，仍由 README「范围内」清单驱动；清单条目改写为「标题：说明」两段式，组件按首个中文冒号拆成磁贴标题与说明，长句不再挤成一块
- 响应式断点：≤760px 降为两列，≤560px 降为单列并取消错落偏移（单列时偏移会变成空白）
- 「清爽纸面」主题同步覆盖磁贴的卡面、描边、高光线与悬停态；极光玻璃主题沿用既有玻璃质感

### 卡片高度与底部空白修正

- 真正原因：卡片装饰光斑 `.set-card::after` 用 `inset: -30%` 画卡面内部流动光，向卡片四周溢出约 1/3 卡高；关于页卡片铺满面板后，这块溢出没有任何裁剪，直接把面板的可滚动高度撑大约 240px，视觉上就是底部一大片空白（页面还会多出一条滚动条）
- 期间还踩过一个坑：网格用 `flex: 1` + `grid-auto-rows: min-content` 拉伸时，行内容超出网格盒会反向扩大滚动区域，反而加重空白；已改为网格不参与拉伸
- 最终方案：
  - 面板与卡片铺满可用高度（`min-height: 100%` + 逐层 `flex: 1`），卡片边框一直包到面板底边
  - 卡片内部用 `.project-features` 的 `justify-content: space-between` 分配品牌头 / 网格 / 页脚，网格 `flex: 0 0 auto` 按内容排布，不拉伸
  - 页脚取消 `margin-top: auto`，交给 `space-between` 定位，避免自动外边距吃掉全部剩余空间
  - `.settings-panel--fill .set-card::after { inset: 0 }`：光斑收进卡片内部，视觉几乎无差别，但不再产生溢出
- 两套主题共用同一套高度规则，极光玻璃与清爽纸面表现一致
