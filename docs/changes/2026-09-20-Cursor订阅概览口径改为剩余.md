# Cursor 订阅概览口径改为剩余

## 日期
2026-09-20

## 类型
fix

## 关联文件
- `src/shared/format.ts` — 新增 `formatRemainingFromUsedPercent`
- `src/renderer/components/SubscriptionPanels.tsx` — Cursor 概览主数值改为剩余百分比，关键指标标注「已用」
- `src/renderer/components/SubscriptionUtils.ts` — provider 卡片摘要行改为「周期剩余」

## 变更摘要

### 问题
Cursor 面板概览把「已用」百分比（`totalUsedPercent`，如 84.01%）当作主数值展示，而它左侧紧挨着账户状态的绿色「可用」徽标，单位又写作「周期总用量」。视觉上被读成「可用 84.01% / 还剩 84.01%」，与真实含义（已用 84.01%）相反；provider 卡片摘要行「周期用量 84.01%」同样存在「用量 = 已用还是剩余」的歧义。

### 调整
1. **概览主数值改为剩余**：`amount = 100 - totalUsedPercent`（`formatRemainingFromUsedPercent`，两位小数，与 `formatUsedPercent` 口径对齐），单位由「周期总用量」改为「周期剩余」；已用值移入副信息，形如「已用 84.01% · 来源 Cookie · 计费周期」。与 Command Code「剩余额度」、DeepSeek「余额」口径统一，绿色「可用」徽标读起来也自然。
2. **关键指标标注口径**：`Cursor Models` / `Other Models` 两项标签补「已用」后缀，避免与概览的剩余口径混淆；`明细模型数` 不变。
3. **卡片摘要行改为「周期剩余」**：`providerSummaryLine` 的 cursor 分支复用同一换算，卡片与面板口径一致。

## 影响范围
- 仅展示层：Cursor 的已用/剩余口径与文案变化，未改任何数据获取、解析或缓存结构
- `totalUsedPercent` 为 null 时仍显示 `--`（剩余与已用一致回退）
- 其余两个 provider（Command Code、DeepSeek）展示不变

## 验证
- `npx tsc -p tsconfig.json --noEmit` 通过
- 人工核对换算：已用 84.01% → 剩余 15.99%，两者相加为 100.00%
- 人工验证（待用户执行）：打开订阅页 Cursor 面板，确认概览显示「剩余 15.99% / 周期剩余」、副信息含「已用 84.01%」，关键指标带「已用」标注，卡片摘要为「周期剩余」
