# 托盘菜单精简与用量流水

- 日期：2026-07-22
- 类型：feature
- 关联文件：src/renderer/App.tsx、electron/tray.ts、electron/main.ts、electron/windows/flow.ts、flow.html、src/renderer/pages/FlowPage.tsx、src/renderer/components/UsageFlowTable.tsx、src/renderer/pages/SettingsPage.tsx、src/shared/types.ts、src/core/normalizer.ts、src/shared/format.ts、vite.config.ts、electron/preload.ts

## 变更摘要

- 悬浮球底部分段 Tab「明细」改为「用量」
- 托盘右键菜单精简为：流水、设置、退出；移除立即刷新与暂停/恢复自动刷新
- 设置页重构：凭据与连接优先、数据刷新 toggle/间隔即时保存、外观降为末位
- 新增用量流水独立窗口，展示 Date (UTC+8)、Type、Model、Tokens、Cost 五列；数据来自 Cookie 周期事件并在 normalizer 中保留为 `usageFlow`

## 影响范围

- 托盘不再提供刷新/暂停入口（悬浮球头部刷新按钮与设置页自动刷新开关仍可用）
- `TokenSnapshot` 新增可选字段 `usageFlow`；official 源流水不可用
- 新增 Vite 入口 `flow.html` 与 IPC `open-flow`

## 验证

- 悬浮球底部显示「概览 / 用量」
- 托盘右键仅流水、设置、退出
- 流水窗五列对齐官网，Date 为东八区，Tokens 含「万」单位
- 无 Cookie 时流水窗提示需配置凭据
- 设置页 Cookie+测试在最上，toggle 与间隔修改即时/自动保存
