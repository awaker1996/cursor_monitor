# 今日百分比稳定性修复

- 日期：2026-07-07
- 类型：fix
- 关联文件：src/core/normalizer.ts、scripts/verify-today-percent.ts

## 变更摘要

- 重构 `todayUsedPercent()`：统一 `costShare` / `tokenShare` 夹取与 `clampTodayPercent` 边界保护
- 当费用份额显著高于 token 份额（≥5%）或出现历史费用缺失可疑场景时，回退到更保守的 token 份额
- 周期事件分页未完整拉取（`totalUsageEventsCount` > 已拉取条数）或今日 token 大于周期 token 时，不再用可能被截断的 token 分母推导，改走费用口径或返回 `null`
- 新增 `scripts/verify-today-percent.ts` 覆盖费用缺失、份额分歧、分页截断、集合关系异常等场景

## 影响范围

- 稳定“今日 API / 今日 Auto + Composer”展示，避免偶发超过对应周期百分比后又恢复正常
- 在 Cursor Dashboard 费用字段不完整或 usage events 分页截断时，减少刷新间跳变

## 验证

- `npm run typecheck` 通过
- `npx tsx scripts/verify-today-percent.ts` 全部场景通过
- 约束：`今日百分比 <= 周期百分比`；同一输入多次归一化结果一致
