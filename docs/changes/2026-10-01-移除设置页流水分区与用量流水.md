## 变更摘要
- 设置窗口由三分区（订阅 / 流水 / 其他）简化为两分区（订阅 / 其他），移除「流水」Tab 与 `FlowPage`
- 移除用量流水相关 IPC：`fetch-usage-flow`、`flow-get-cached`；preload 与渲染层类型同步删除
- 移除主进程流水链路：`UsageFlowCache`、`ProviderManager` 的流水拉取与平台分发、`CookieProvider` 的流水分页方法、`normalizer` 的流水页构建
- 移除共享模块 `usageFlowDates` / `usageFlowFormat` / `usageFlowPagination` 与 `formatUsageFlowDate`
- 移除 Command Code「流水凭据（网页会话）」凭据种类与配置 UI，`SubscriptionCredentialKind` 收敛为 `apiKey` / `usageToken`
- 清理 `styles.css` 中流水页、平台筛选、分页与表格样式
- 清理 README 中流水相关章节、目录结构、模块表、IPC 表、验收项与版本规划
- 删除流水专题变更归档并在 `docs/changes/README.md` 中移除对应索引

## 影响范围
- 设置窗口仅保留订阅与其他分区；`#flow` hash 不再有效
- 订阅页不再展示 Command Code 流水凭据配置
- 主链路快照（今日/周期用量、Included Usage）与订阅查询不受影响
- `ProviderManager` 不再持有 `CommandCodeProvider` 引用

## 验证
- `npm run typecheck` 通过

- 订阅页 Cursor / Command Code / DeepSeek 面板与凭据配置正常，无「流水凭据」入口
- 悬浮球概览、Included Usage 与托盘悬停摘要正常刷新
