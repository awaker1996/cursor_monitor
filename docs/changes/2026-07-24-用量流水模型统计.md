## 变更摘要

- 流水窗按当前筛选周期拉取聚合接口（失败时回退分页事件）汇总各模型 token
- `UsageFlowDisplay.modelStats` 含总 token 与各模型占比
- 流水页表格上方展示条形图统计，直观对比模型用量
