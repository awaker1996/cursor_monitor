# 设置页：账户、数据刷新与关于分区美化

- 日期：2026-11-01
- 类型：feature, style
- 关联文件：`src/renderer/components/AccountCard.tsx`, `src/renderer/pages/SubscriptionsPage.tsx`, `src/renderer/components/SettingsTabContent.tsx`, `src/renderer/components/ProjectFeaturesCard.tsx`, `src/renderer/pages/SettingsPage.tsx`, `src/renderer/mockElectronAPI.ts`, `src/renderer/styles.css`, `README.md`

## 变更摘要

- **顶栏**：原来标题栏写「设置」、顶栏再写一遍「设置」；改为产品标识 + 「偏好设置」胶囊 + 右侧带呼吸点的「改动即时保存」提示，去掉重复大标题
- **账户与订阅 · 工具栏**：由一行灰字改为「图标 + 两行状态 + 主按钮」——第一行上次查询时间，第二行「N/M 已配置」胶囊与自动刷新说明；「刷新全部」加刷新图标，查询中图标旋转
- **账户与订阅 · 平台卡**：
  - 卡头新增**平台牌**：首字母 + 品牌渐变块（Cursor 蓝青 / Command Code 紫粉 / DeepSeek 青蓝），右下角一枚健康状态点（正常 / 未配置 / 异常）
  - 卡片顶部一条平台品牌细线；未配置时退成灰色，卡片底色压低半档
  - 指标区：主值加大到 13px 并加重，标签压小；进度条由 4px 加粗到 5px，改品牌 / 语义渐变并带微光；注释限制两行
  - 页脚「数据来源 · 更新时间」加极细分割线与小圆点，和指标区分层
  - **未配置卡**改为「图标 + 标题 + 一句说明 + 去配置」的引导块：点击按钮直接展开卡片并打开凭据配置；未配置时不再显示上次缓存指标，避免和「未配置」自相矛盾
- **数据刷新**：卡片顶部新增三块读数 —— 刷新节奏（每 N 秒/分钟 + 是否在自动拉取）、每日请求（按间隔估算次数）、数据新鲜度（两次拉取之间的最大延迟）。开关与间隔滑杆保持不变
- **关于**：整段项目符号改为「品牌头（渐变标记 + 名称 + 简介）+ 两列要点网格（每条一枚对勾方块）+ 页脚（凭据与数据仅保存在本机 · 版本号）」，窄窗自动降为单列
- **用量明细表**：增加行悬停高亮与列间距，长表扫读更稳
- **浏览器预览**：`mockElectronAPI` 补齐三平台（Cursor / Command Code / DeepSeek）的订阅信息与用量演示数据，纯浏览器打开 `/settings.html` 即可看到已配置卡片、指标条与展开明细

## 影响范围

- `AccountCard` 新增 `account-card--<providerId>` 类与平台牌结构，`view` 在未配置时由页面传 `null`（不再渲染缓存指标）；展开 / 收起与 ARIA 属性不变
- `SubscriptionsPage` 工具栏改结构，新增 `configuredCount` 与「去配置」回调；刷新逻辑、凭据保存逻辑与 toast 均未改动
- `DataRefreshPrefs` 新增纯展示的读数区，数值全部由现有 `refreshIntervalSec` 推导，不新增设置项、不发额外 IPC
- `ProjectFeaturesCard` 仍从 `README.md` 的「范围内」列表派生要点，仅渲染结构变化；新增 `package.json` 版本号展示
- `SettingsPage` 顶栏改结构（移除 `h1 设置` 与副标题 `<p>`），标题栏组件未改动
- `mockElectronAPI` 新增演示数据常量，仅在浏览器预览生效（Electron 走 preload 注入的真实 API）
- 样式集中在 `styles.css` 的账户 / 数据 / 关于 / 顶栏区块，并为 `html[data-ui-style='calm']` 补齐纸面配色；删除了已无引用的 `.provider-card__dot*` 规则

  - 账户区：把 DeepSeek 置为未配置后核对引导块与「去配置」按钮，卡片不再显示旧指标

  - 关于区：两列网格与页脚在两套主题下的表现，720 宽度降为单列
  - 顶栏：产品标识、偏好设置胶囊、自动保存提示在两种主题下的对比
- Electron 实例本轮未实机启动：改动均为渲染层结构与样式，主进程与 IPC 未改动
