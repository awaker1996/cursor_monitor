# 悬浮球窗宽抖动修复

- 日期：2026-07-20
- 类型：fix
- 关联文件：electron/windows/floatingBall.ts、electron/floatingBallDock.ts、electron/main.ts、src/renderer/styles.css

## 变更摘要

- 引入统一 `ORB_PANEL_WIDTH = 300`，贴边 / 展开 / 取消贴边共用同一宽度，贴边仅改变高度
- 移除 `applyOrbMode('hover')` 遗留的 `280×200` `setBounds`，避免运行一段时间后宽度被拉宽/跳变
- `applyExpandedPanelLayout` 不再改尺寸，仅校验窗宽
- 用 `setMinimumSize` / `setMaximumSize` 锁定宽度，并在 `will-resize` / `resized` 中纠正漂移
- 面板改为固定 `276px`（300 − 左右各 12px padding），不再 `width: 100%` 跟随异常窗宽拉伸

## 影响范围

- 悬浮球贴边、取消贴边、长时间运行后的窗体/弹窗宽度稳定性

## 验证

- `npm run typecheck`
- 完全重启应用后：点击展开弹窗宽度与刚启动时一致，等待多次自动刷新后宽度不变
- 拖动贴边再拖出：宽度不变，仅高度 548↔448
- 概览 ↔ 明细切换窗宽不变
