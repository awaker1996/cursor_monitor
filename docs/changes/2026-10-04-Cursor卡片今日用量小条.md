## 变更摘要

- `CursorSubscriptionData` 新增 `cursorModelsTodayUsedPercent` / `otherModelsTodayUsedPercent` 两个字段，由 `CursorProvider` 直接从快照的 `metrics.autoTodayUsedPercent` / `metrics.apiTodayUsedPercent` 透出；今日口径本来就在快照里（悬浮球与弹窗一直在用），此前只是没进入订阅卡片
- 卡片收起态小条从「仅 Command Code」升级为按 provider 分发：Cursor 展示 `今日 Cursor` 与 `今日 Other` 两根小条，Command Code 保持 5h / 周 / 月，DeepSeek 不出小条
- `commandCodeCollapsedLimits` 重构为 `providerCollapsedUsage`，返回统一的 `CollapsedUsageChip`（`key` / `label` / `percent` / `title`），提示文案统一带上完整口径名称，如「今日 Other Models已用 92%」
- 缺少今日数据（刷新失败或缓存回填未命中）时不补 0%、不出小条，避免把「无数据」误读成「没用量」
- 新增 `clampPercent` 统一百分比夹取，`limitPercent` 改为复用它，页面内重复的 `Math.min/Math.max` 一并去掉
- 小条分组的无障碍名称按平台区分：Cursor 为「今日用量摘要」，其余为「限额摘要」

## 影响范围

- 仅设置页「账户与订阅」的 Cursor 卡片收起态，展开态面板、悬浮球、弹窗与接口请求逻辑均未改动
- `CursorSubscriptionData` 新增的是必填字段，仅 `CursorProvider` 一处构造，已通过 typecheck 确认无其他构造点漏改
- 视觉复用既有 `limit-chip` 样式，Cursor 卡片与 Command Code 卡片的小条外观一致；百分比 ≥90% 显示红色、≥70% 显示黄色
