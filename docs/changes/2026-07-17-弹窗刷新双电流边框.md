# 弹窗刷新双电流边框

- 日期：2026-07-17
- 类型：feature
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css、src/renderer/components/MetricRow.tsx

## 变更摘要

- 刷新拉取数据期间，在整个悬浮球弹窗外框启用双电流环绕动画
- 绿/蓝两道电流相位错开，并反向旋转；外框带轻微辉光
- 用 `panel-frame` 包裹滚动面板，避免边框随内容滚动错位

## 影响范围

- 仅影响展开弹窗刷新态视觉反馈
- 依赖既有 `isRefreshing`（pendingRefresh / poller fetching）

## 验证

- `npm run typecheck`
- 点击刷新，确认整弹窗外框有绿+蓝双电流环绕，结束后消失，且面板滚动时边框仍贴合外框

## 补充（同日）

- 加粗描边、拉长光尾、白芯高亮，并叠加多层外发光，提升双电流可见度
- 去掉刷新态整框描边/外发光与半周光尾，避免出现常显矩形框；电流改为短亮段环绕
