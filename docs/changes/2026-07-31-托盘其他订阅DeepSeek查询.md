# 托盘"其他订阅"DeepSeek 订阅查询

- 日期：2026-07-31
- 类型：feature
- 关联文件：electron/tray.ts、electron/main.ts、electron/preload.ts、electron/windows/subscriptions.ts、src/shared/subscriptionTypes.ts、src/security/CredentialVault.ts、src/core/subscriptions/types.ts、src/core/subscriptions/DeepSeekProvider.ts、src/core/subscriptions/SubscriptionManager.ts、src/renderer/pages/SubscriptionsPage.tsx、src/renderer/subscriptions-main.tsx、src/renderer/vite-env.d.ts、src/renderer/styles.css、subscriptions.html、vite.config.ts

## 变更摘要

- 托盘右键菜单在"查看流水"之后新增"其他订阅"菜单项，点击打开独立弹窗（520×600 单例窗口，复用 flow/settings 多页窗口模式，新增 `subscriptions.html` vite 入口）
- 新增订阅核心层 `src/core/subscriptions/`：`SubscriptionProvider` 接口 + `SubscriptionManager` 注册表模式，后续新增其他订阅源只需实现接口并在 Manager 构造函数中注册
- 实现 `DeepSeekProvider`：调用官方接口 `GET https://api.deepseek.com/user/balance`（Bearer API Key 鉴权），解析账户可用状态与各币种总余额/赠送余额/充值余额；401/403、非 2xx、超时均返回中文错误提示；超时沿用设置中的 `requestTimeoutSec`
- `CredentialVault` 扩展通用多账户凭据方法 `saveSecret/getSecret/clearSecret/hasSecret`（keytar 优先、safeStorage 文件回退），原 cookie 四方法改为委托实现，旧 `.credential` 文件名保持兼容；DeepSeek API Key 存于账户 `deepseek-api-key`
- 新增共享类型 `src/shared/subscriptionTypes.ts`（提供方元信息、DeepSeek 余额数据、查询结果可辨识联合）
- 新增 IPC：`open-subscriptions`、`subscription-list-providers`、`subscription-save-key`（校验非空）、`subscription-clear-key`、`subscription-fetch-info`，preload 与 vite-env.d.ts 同步暴露
- 新增弹窗页面 `SubscriptionsPage`：提供方 tab（当前仅 DeepSeek）、API Key 密码框配置区（保存/清除、已配置状态提示、不回显明文）、手动查询与余额表格展示；样式复用 settings 页体系并新增 `subscription-` 前缀类
- DeepSeek 查询不纳入 Poller 自动轮询，仅弹窗内手动触发

## 影响范围

- 托盘右键菜单（新增一项，其余不变）
- 凭据存储（CredentialVault 内部重构为通用方法，cookie 行为与存储位置不变）
- 新增独立"其他订阅"窗口与对应 IPC；悬浮球、流水、设置等既有窗口不受影响

## 验证

- `npm run typecheck` 通过（electron 与 renderer 两套 tsconfig）
- `npm run build` 通过，`dist/subscriptions.html` 及对应 chunk 正常产出
- 人工验证（待用户执行）：托盘右键出现"其他订阅"→ 弹窗保存 DeepSeek API Key → 查询展示余额；未配置 Key 时查询按钮禁用并提示；错误 Key 返回"API Key 无效或已过期"
