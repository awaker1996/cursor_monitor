# 明细面板统一体验与展开丝滑动画

- 日期：2026-07-18
- 类型：feature
- 关联文件：electron/windows/floatingBall.ts、electron/main.ts、electron/floatingBallDock.ts、src/renderer/App.tsx、src/renderer/styles.css、src/renderer/components/IncludedUsageTable.tsx、src/renderer/components/IncludedUsageModelName.tsx

## 变更摘要

- 未贴边时悬浮球窗口固定为 360×520，展开/收起不再 `setBounds`，消除点击顿挫
- 面板进出场：上浮 + 淡入 + 微缩放（250ms），收起反向动画后再卸载 DOM
- 概览与明细同宽，切换视图不再改窗体尺寸
- 明细 Usage 强调色与左侧色条改为蓝灰系（`#93c5fd` / `#60a5fa`），去除紫色
- 超长 API 名称仅溢出时启用慢速单行无限滚动（14s 循环）

## 影响范围

- 悬浮球点击展开/收起交互
- Included Usage 明细列表视觉与长名称展示
- 贴边 dock/undock 仍使用 300×448 peek 尺寸，undock 恢复 360×520

## 验证

- `npm run typecheck`
- 点击悬浮球展开/收起：窗体不跳变，面板丝滑进出
- 概览 ↔ 明细：宽度一致
- 明细无紫色强调；短名称静止，长名称慢速滚动
- 贴边、拖出、拖拽行为正常
