# 两窗动态玻璃与开关 UI 统一

## 日期
2026-10-05

## 类型
style

## 关联文件
- `src/renderer/styles.css`

## 变更摘要

- 悬浮球弹窗面板 `.floating-ball__panel` 底色由近乎不透明的纯色 `rgba(22, 22, 40, 0.98)` 换成与设置页 `.settings-page` 同源的深海军蓝渐变基底
- 弹窗面板新增 `::before` 页面级极光画布：与设置页同一组光斑配色、尺寸与漂移节奏（复用 `pageAuroraDrift` 关键帧），两窗玻璃语言一致
- 面板直接子元素统一 `position: relative; z-index: 1`，内容浮于极光之上（与设置页 topbar/layout 同规则）；刷新进度条随后重新声明 `position: absolute` 不受影响
- 设置 Switch 开关补齐玻璃质感：深蓝玻璃底 + 顶部内高光 + `glassShine` 扫光（错相位 delay 1.2s，开启态归 0s），与弹窗卡片共享同一光泽语言
- `prefers-reduced-motion` 下极光画布与开关扫光均停帧，静态光斑与玻璃质感保留

## 影响范围

- 仅视觉层：弹窗概览/用量两视图、设置页数据刷新/悬浮球分区的开关外观
- 不改数据、不改交互、不改窗口尺寸；`.floating-ball__panel::after` 仍为 Aurora 流光边框，refreshing 电弧伪元素不受影响

## 验证

- `npm run typecheck` 通过
- `npm run build` 通过
- 弹窗与设置窗并排对比：两窗底色、极光色相、漂移节奏一致；开关扫光与卡片光泽同语言
