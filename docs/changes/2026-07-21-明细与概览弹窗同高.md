# 明细与概览弹窗同高

- 日期：2026-07-21
- 类型：fix
- 关联文件：src/renderer/styles.css

## 变更摘要

- 概览 / 明细切换时弹窗高度差过大：明细被长列表撑高，概览保持内容高度
- 展开面板固定为 `--orb-panel-height: 380px`（与概览视觉高度对齐），两侧共用
- 明细列表在固定高度内滚动；底栏「概览 / 明细」用 `margin-top: auto` 钉在底部

## 影响范围

- 悬浮球展开弹窗概览 ↔ 明细切换时的高度一致性

## 验证

- 展开概览后切换明细：外框高度不变，仅列表区域可滚动
- 明细切回概览：高度仍一致，底栏位置不变
