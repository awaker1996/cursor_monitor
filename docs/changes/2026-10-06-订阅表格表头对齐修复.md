# 订阅表格表头对齐修复

## 日期
2026-10-06

## 类型
fix

## 关联文件
- `src/renderer/styles.css`

## 变更摘要

- 根因：`.sub-table th { text-align: left }`（类 + 标签，特异性 0,1,1）压过 `.sub-table__num { text-align: right }`（单类，0,1,0），表头虽挂右对齐类仍渲染为左对齐，出现「表头贴左、数值贴右」的纵向错位；列越宽偏差越大（占比列差约 85px）
- 修复：新增更高特异性规则 `.sub-table th.sub-table__num, .sub-table th.sub-table__value { text-align: right }`，表头数值列与表体数值共享右缘
- 覆盖订阅明细表（Cursor Models / Other Models / DeepSeek 模型表）与两列表（指标 / 数值）的表头；Aurora 与清爽纸面两主题同受益

## 影响范围

- 仅表头文字对齐；列宽、字号、配色不变

## 验证

- 在真实嵌套结构（面板 → 账户卡 → 订阅分区）注入同构表格，Range 精测表头与数值文字右缘：修复前相差数十像素，修复后完全一致（625.5/625.5、709/709）
