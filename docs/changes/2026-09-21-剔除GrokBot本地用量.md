# 剔除 Grok Bot 本地用量

- 日期：2026-09-21
- 类型：fix
- 关联文件：src/core/normalizer.ts、src/core/providers/ProviderManager.ts、scripts/verify-today-percent.ts、scripts/verify-included-usage.ts、scripts/verify-usage-flow-format.ts、docs/changes/README.md

## 变更摘要

- 本地「今日 Cursor Models %」、Included Usage / 订阅模型明细、用量流水精确剔除 `grok-bot-automation`、`grok-bot-default`
- 周期 Cursor Models % 仍使用官方 API `autoPercentUsed`（不改写账单口径）
- Included Usage 占比分母保留 bot 成本/token，避免把 bot 份额摊给 Composer / IDE Grok 等模型
- 用量流水在拉全量后本地分页，过滤后重算总条数与页码

## 影响范围

- 悬浮球今日 %、托盘摘要今日分项、订阅页模型表 / Included Usage、设置页用量流水
- IDE 内普通 `grok-*` 仍计入 Cursor Models
- 官方周期总消耗 / 周期池 % 展示不变

## 验证

- `npx tsx scripts/verify-today-percent.ts`
- `npx tsx scripts/verify-included-usage.ts`
- `npx tsx scripts/verify-usage-flow-format.ts`
