# 设置页连接测试详细结果

- 日期：2026-07-17
- 类型：feature
- 关联文件：src/shared/types.ts、electron/main.ts、src/renderer/pages/SettingsPage.tsx、src/renderer/components/TestConnectionResultPanel.tsx、src/renderer/styles.css

## 变更摘要

- 连接测试成功时展示完整调用结果：耗时、数据源、数据版本、获取时间、总消耗、账单周期、Included Usage 状态
- 展示 Token 配额与用量分项（复用 MetricRow 与现有格式化逻辑）
- `TestConnectionResult` 新增 `durationMs`，主进程记录接口调用耗时

## 影响范围

- 设置页「连接测试」结果区域由单行文案改为结构化详情面板
- 失败时仍显示错误信息与耗时

## 验证

- `npm run typecheck`
- 配置 Cookie 后点击「测试连接」，确认成功结果展示分项用量与元信息
- 未配置 Cookie 或 Cookie 无效时，确认失败信息与耗时可见
