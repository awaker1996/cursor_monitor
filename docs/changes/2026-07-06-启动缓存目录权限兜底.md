# 启动缓存目录权限兜底

- 日期：2026-07-06
- 类型：fix
- 关联文件：electron/main.ts

## 变更摘要

- 在主进程启动早期新增 Chromium 缓存目录初始化逻辑
- 显式创建并设置 `sessionData`、`disk-cache-dir`、`gpu-shader-disk-cache-dir`
- 将运行时缓存目录统一指向 `%AppData%/<AppName>/runtime` 下可写位置
- 初始化失败时记录 warning，避免影响主流程启动

## 影响范围

- 修复部分 Windows 环境下缓存目录无权限导致的启动错误日志（`Unable to move the cache` / `Gpu Cache Creation failed`）
- 降低因旧缓存目录只读、安装目录权限限制导致的 Chromium 缓存初始化失败风险

## 验证

- 本地 `npm run typecheck` 通过
- 启动应用后不再出现 `cache_util_win.cc` / `gpu_disk_cache.cc` 权限相关报错
