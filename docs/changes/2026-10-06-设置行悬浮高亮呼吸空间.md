# 设置行悬浮高亮呼吸空间

## 日期
2026-10-06

## 类型
fix, refactor

## 关联文件
- `src/renderer/styles.css`

## 变更摘要

- 问题：设置行（`.set-row`）行内边距左右为 0，悬浮高亮块与行内文字、控件左右贴合，无呼吸空间
- 修复：行内边距改 `13px 12px` 并以 `margin: 0 -12px` 抵消——悬浮高亮向内容两侧各延伸 12px（保留圆角），行内容位置一像素不变，与卡片其他元素仍严格对齐
- 行间分隔线由 `border-top` 改为 `::before` 伪元素绘制并向内收 12px：分隔线保持原内容宽度，与加宽后的悬浮胶囊自然分离；calm 层分隔线色同步迁移
- 排查全部卡内可悬浮模块（应用图标框、订阅表格行、关于页、凭据配置行）：仅 `.set-row` 存在高亮贴内容问题，其余为紧凑列表正常密度，未改动

## 影响范围

- 设置页全部使用 SettingsRow 的卡片（数据刷新 / 外观 / 悬浮球行为等），Aurora 与清爽纸面两主题共用

## 验证

- 浏览器 dev 预览：数据刷新 / 外观 / 悬浮球分区行悬浮截图，高亮两侧留白自然、内容对齐无变化、分隔线宽度不变
