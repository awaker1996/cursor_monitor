## 变更摘要
- 设置页分区标题（账户与订阅 / 数据刷新 / 外观 / 关于）由「文字左侧贴一根色带」改为**玻璃胶囊容器**：`.settings-panel__header h2` 用 `display:flex; width:fit-content; padding:4px 14px; border-radius:999px` 承载底色、描边与投影
- 新增 8 个胶囊设计令牌 `--pill-bg` / `--pill-bg-soft` / `--pill-border` / `--pill-border-soft` / `--pill-shadow` / `--pill-shadow-soft` / `--pill-text` / `--pill-text-soft`：极光玻璃写在 `:root`，清爽纸面在 `html[data-ui-style='calm']` 内整体换值，组件侧零覆盖，两主题 DOM 与规则完全同构
- 删除纸面主题中 `.settings-panel__header h2` 的色带本体（`background: … left center / 4px 14px no-repeat` 与 `padding-left:11px`）；该 h2 的纸面覆盖规则整体移除，改由 `--pill-text` 取色
- 移除侧边导航激活项左侧 3px 彩色索引条：极光与纸面两条 `.settings-nav__item.is-active::before` 规则整条删除，不新增替代标记；激活态由滑移指示器（本身即胶囊）、字重与激活色共同承担
- 订阅卡片内小节标题（关键指标 / 周期与账户 / 用量明细 / Grok Bot 周用量）统一为同族小号胶囊：`.sub-block__head .sub-section-title` 引用 `--pill-*-soft` 系列，基础 `.sub-section-title` 的颜色也改由 `--pill-text-soft` 提供
- 遗留清理：删除无任何引用方的 `TokenBadge.tsx` 组件与 `.token-badge*` 整块样式（含 `border-left: 3px solid` 彩条）；删除样式表中已无对应规则的死钩子 `CardAccent` 类型、`ACCENT_CLASS` 映射与 `GlassCard` 的 `accent` 属性及其 5 处传参

## 影响范围
- **两主题此前不对称**：设置页分区标题的色带只存在于清爽纸面主题，极光玻璃主题没有；本次两主题统一为胶囊结构，仅配色不同
- 胶囊圆角沿用项目既有胶囊语汇（`.limit-chip` / `.health-pill` / `.account-card__plan` / `.settings-nav__thumb` 均为 999px），与侧边导航滑移指示器同形，分区身份语言自洽
- 胶囊不带动画：极光玻璃的流光语汇已由卡片边框 `conic-gradient` 与标题栏 `::after` 承担；再给标题加流光会与纸面主题「静态无动效」原则冲突并破坏同构
- 分区标题字号 / 字重 / 字距不变（16px / 700 / -0.01em），小节标题字号字重不变（14px / 600）；仅增加胶囊表面
- 描述文字与标题的间距由 2px 调整为 8px（胶囊内边距 + 标题下边距），标题与描述不再贴得过近
- 纸面主题 `--pill-text-soft` 取 `--calm-ink-2`，与改动前 `.sub-section-title` 的纸面色值一致，文字观感不变
- 悬浮球面板不受影响：其 `included-usage__section-head` 是底色块而非色带；`.included-usage__model-list` 的 `border-left: 2px` 是模型列表的层级缩进引导线，表达父子关系而非分区标识，保留不动
- `.metric-row*` 样式块虽已无渲染方，但不含任何色带且注释明示 kept for compatibility，本次不清理以控制改动面
- `TokenBadge` 删除前已确认无引用方：`App.tsx` 用 `MetricRow` / `IncludedUsageTable` / `ErrorHint`，`SubscriptionsPage.tsx` 用 `SubscriptionPanel` / `TestConnectionResultPanel` / `ErrorHint`，`TestConnectionResultPanel.tsx` 用 `MetricRow`
- 未改动任何信息架构、交互与数据逻辑；README 中 4 处「无左色带」均描述悬浮球卡片（本就没有色带），依然准确，仅 FR-11 补记新的标题语言
