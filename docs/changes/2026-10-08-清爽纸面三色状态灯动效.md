## 变更摘要

### 一、清爽纸面主题的三色状态灯

- 弹窗 header 左侧三色状态灯此前在清爽纸面主题下被整体去动效（`animation: none` + 静态哑光三色点）。按反馈恢复「红 → 黄 → 绿」依次轮播，但换成纸面语的**哑光慢呼吸**，与极光玻璃的玻璃灯位保持动效存在感一致、视觉强度分层
- 新增 `calmTrafficLightRed / Yellow / Green` 三组关键帧：仅做颜色明暗起伏（熄灭淡色 ↔ 点亮正色），并伴随描边透明度 0.1 → 0.16 的极轻变化；不使用极光玻璃版那样的 `transform: scale()` 弹跳与彩色外发光晕，避免在「久看不累」的纸面主题里出现跳动与眩光
- 节奏放慢至 3.6s 周期（极光 2.7s），delay 0s / 1.2s / 2.4s 保持等比错相位
- 修复首帧黑洞：三灯 `animation-delay` 期间关键帧尚未生效，元素回落到极光基底的深蓝紫底 + 深色多层阴影，视觉上是三个黑洞。给 calm 主题补静态基底（`.traffic-light` 中性灰 + 各灯熄灭淡色 + 细描边），delay 期间即显示正常熄灭态
- 补齐降级兜底：上方 `prefers-reduced-motion` 规则带 `animation: none !important` 并写死 `#16162b` 底色，追加 `html[data-ui-style='calm']` 分支，把该场景下的三灯还原为静态哑光三色（而非极光的深蓝紫熄灭色）

### 二、清爽纸面主题的刷新边框

- 极光的双色电弧（绿/蓝 conic 光斑 + 三层 drop-shadow 白色辉光，1.45s/1.8s 双向高速环绕）在纸面主题下过于眩目，calm 覆盖层改为「水流环绕」：一条品牌蓝**水头拖尾**的连续光带沿边框顺时针环流，头部是 `accent → accent-deep` 的浓色段，尾部经 0.55 → 0.22 透明度渐弱收进 `accent-soft` 通道色，conic 首尾相接无缝；3s 一圈匀速，无光晕无爆闪。`prefers-reduced-motion` 降级为静态渐变环
- 迭代过程：先试「虚线跑马灯」（风格跳跃）、再试「整圈描边呼吸」（不明显）、「短光带进度条」（不够现代），最终定为水流环绕
- 移除纸面主题弹窗 header 下缘的品牌渐变缝线（`.floating-ball__panel-header` 的三色 1px 背景），按反馈该横线视觉多余；header 背景改为 none
- 修复概览视图底部卡片被切换栏裁切：贴边 peek 窗高 448 时 body 可用高度不足，`overflow: hidden` 把最后一张 metric 卡下半截裁在「概览/用量」切换上方。概览视图 body 改为纵向可滚（与用量视图 `__body` 同款 6px 细滚动条、极光白 0.18 / 纸面蓝灰 0.3 两套 thumb），底部加 4px padding 呼吸；未贴边 548 窗高下内容完整时不出现滚动条，视觉无变化

### 三、按钮 tooltip 重设计

- 悬浮球弹窗三个 header 按钮（刷新 / 设置 / 收起）此前依赖原生 `title` 属性，显示的是操作系统默认的系统气泡（延迟长、样式不可控、与双主题风格割裂）
- 改为 `data-tip` 驱动的自绘气泡（`App.tsx` 去掉三处 `title`，改 `data-tip`），CSS 单伪元素 `::after` + `content: attr(data-tip)` 实现，零 JS、零 DOM 额外节点
- 视觉语言：现代 tooltip 做法——无拼接箭头（`::before` 旋转方块做三角在此处易与描边打架且溢出角落），圆角 7px、细描边、柔和投影、11px 字重 500；延迟 0.3s 淡入并轻微上浮 3px
- 双主题适配：极光 `#2a3550` 深蓝紫底 + 浅色字 + 重投影；纸面白卡 + `--calm-line-strong` 描边 + `--calm-ink` 墨字 + 轻纸影
- 修层叠：`floating-ball__panel > *` 给所有子元素 `z-index: 1`，header 与 panel-body 同级，气泡从 header 下缘探出会被后渲染的 body 遮住。追加 `.floating-ball__panel-header { z-index: 3 }`
- 无障碍：`aria-label` 保留不变，`title` 移除不影响读屏；新增 `:focus-visible` 分支，键盘 Tab 聚焦也出气泡
- `prefers-reduced-motion` 降级：去掉上浮位移与 0.3s 延迟，`transform: none` + 0.1s 即时显隐

## 影响范围

- 悬浮球弹窗 header 三色灯、刷新边框（仅纸面主题）；三个 header 按钮的悬停提示（双主题）
- 极光玻璃主题的三色灯与刷新边框不受影响；数据链路无改动
- 三色灯仍为纯装饰动画，与健康状态 / 用量数据完全解耦

- 构建产物核验：新 CSS 含 `data-tip` 规则块与 `.floating-ball__panel-header` 的 `z-index: 3`
- 浏览器 dev 预览（`:5180/index.html`）：纸面主题三灯 3.6s 轮播无抖动；按钮悬停 0.3s 后气泡在其下方浮现，未被面板内容遮挡；开 `prefers-reduced-motion` 后气泡即时显隐无位移
