## 变更摘要
- 设置窗口去掉顶部「订阅 / 其他」两个 Tab，改为单页设置中心：账户与订阅（高频）+ 运行行为与外观（低频）上下排列
- 订阅区由单提供方切换视图改为账户卡片纵向列表：默认全部收起只看一行摘要，点击头部展开明细、刷新与凭据配置；每张卡片独立刷新与独立凭据折叠
- 状态文案精简为正常 / 未配置 / 异常三态 pill，完整说明保留在悬停提示中
- Command Code 收起态直接展示 5 小时与每周限额小条（含颜色与百分比），无需展开即可关注
- Cursor 套餐展示：`usage-summary` 顶层 `membershipType` 经归一化进入 `TokenSnapshot` 与 `CursorSubscriptionData`，收起态显示套餐 pill（如 Pro），展开态「周期与账户」首行展示订阅套餐
- Command Code 套餐 pill 走套餐 `planId` 真实数据（如 Go），与展开态套餐行口径一致
- 运行行为与外观改为固定 2×2 卡片：数据刷新（主卡片强调）、用量统计、悬浮球行为、应用图标；卡片增加标题色条与开关底纹，窄窗 700px 以下回落单列
- 项目功能说明折叠为底部「关于与功能说明」，默认收起不再抢占首屏
- 设置窗口默认尺寸由 1120×720 收窄为 840×700（最小 720×560），内容最大宽度收至 800
- Electron 移除 `SettingsTab` 类型与 hash 定位逻辑，设置窗口直接打开单页；删除无引用的 `TabBar` 与 `ProviderSwitcher` 组件及旧 Tab 样式

## 影响范围
- 设置窗口无 Tab、无 hash 路由，旧 `#subscriptions` / `#settings` 入口统一渲染单页
- 订阅页默认三张卡片均为收起态；刷新全部按钮位于账户区工具栏，自动刷新仍读取同一份刷新配置
- Cursor 官方链路无套餐字段时不展示套餐 pill，不写死默认值
- 悬浮球概览 / 用量、托盘、主链路快照不受影响
