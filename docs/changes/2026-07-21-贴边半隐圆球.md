# 贴边半隐圆球

- 日期：2026-07-21
- 类型：feature
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css、electron/floatingBallDock.ts、electron/windows/floatingBall.ts

## 变更摘要

- 贴边态由半胶囊 peek 改为 AssistiveTouch 风格半隐圆球
- 贴边与未贴边共用主球 DOM（进度环 + 中心百分比），视觉一致
- 闲置：向边缘移出约 50%，`opacity: 0.4`
- 悬停：向屏幕内滑回约 12%，`opacity: 1`
- 四边（左/右/上/下）对称适配；贴边时关闭 `orbBreathe` 避免半隐跳动
- 移除 `.floating-ball__peek*` 胶囊样式与相关 SVG 计算

## 影响范围

- 悬浮球贴边外观与 hover 反馈
- 点击展开、拖出 undock 交互不变

## 验证

- `npm run typecheck`
- 四边贴边：半圆露出、闲置 40% 透明
- 悬停滑入变实；点击/拖出 undock 正常
- 未贴边主球动效不受影响

## 补充（同日）

- 半隐位移改到 `orb-wrap` 的负 margin（不再用 orb `transform`），命中区与视觉一致
- 拖出 undock 改为 `inPlace`：保留当前拖拽位置并补偿 margin 切换，避免光标落在球外上方
- 贴边拖出：`move-window` 不再重复 `setPosition`；按球心统一计算四边 undock 补偿（修复顶部贴边拖出抖动）
- 顶部贴边：`justify-content: flex-start` 使球贴窗口顶部；拖拽中禁用 margin 过渡
- 拖出补偿去掉重复的 `heightDelta` 扣减（`to.y` 已按 548 高度计算），修复光标落在球下方
- 拖出瞬间：undock 按**贴边球心 + 抓取偏移**定位，拖拽中保持短窗高与贴边 CSS；松手时再扩高并补偿 dock→undocked 布局差，消除瞬间跳动
- 拖出 undock 改为一次性切到完整未贴边布局（548 高 + 未贴边球心 + 立即广播 dock null）；松手仅做贴边检测，不再扩高/补偿，避免球位跳动
- 拖拽中强制完整球体 margin 与 `overflow: visible`，避免半隐贴边样式裁切球体
- 贴边恢复：`getDockedWindowBounds` 按球心坐标补偿 548→448 高度变化，消除松手贴边时球位跳变
- 拖拽全程固定容器 `align-items`/`justify-content` 为未贴边默认值，屏蔽 dock 类名 IPC 延迟导致的对齐切换抖动
