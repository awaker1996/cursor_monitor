# 贴边 peek 迷你圆环美化

- 日期：2026-07-06
- 类型：feature
- 关联文件：electron/floatingBallDock.ts、src/renderer/App.tsx、src/renderer/styles.css

## 变更摘要

- 贴边/undock 窗口保持固定 300×448，仅 reposition 不再缩放，消除拖出时桌面矩形闪烁
- 贴边态透明区域启用鼠标穿透，仅 peek 条可交互
- peek 由单色块 + health-dot 升级为迷你 SVG 进度环 + 余量百分比，与主悬浮球视觉统一
- 新增玻璃质感背景、健康色 accent 光晕、`peekBreathe` 呼吸动画
- 四边贴边均适配：left/right 纵向布局，top/bottom 横向布局
- peek 改为透明外层 + 胶囊形内壳（`peek-shell`），与主 orb 渐变/光晕统一，消除矩形背景感
- 移除 `title` 常驻提示，改为 `aria-label` 供无障碍读取
- hover 时向屏幕内滑出 3px，accent 边增亮

## 影响范围

- 贴边/undock 交互逻辑不变
- 主悬浮球 orb 样式不变

## 验证

- `npm run typecheck` 通过
- 四边贴边显示迷你圆环 + 余量数字
- 健康色 accent 与圆环颜色正确
- hover 滑出、点击/拖出 undock 正常
