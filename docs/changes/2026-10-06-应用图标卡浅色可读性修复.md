# 应用图标卡浅色可读性修复

## 日期
2026-10-06

## 类型
fix

## 关联文件
- `src/renderer/styles.css`

## 变更摘要

- 根因：`.icon-pick__name`（#e8eeff 近白）与 `.icon-pick__hint`（浅蓝灰）沿用 Aurora 深色主题配色，清爽纸面覆盖层漏掉该组件，浅色文字压在浅色卡片上几乎不可读
- 补齐 calm 覆盖：名称改墨色、说明改中灰、默认占位改中灰；图标预览框由深蓝棋盘格换浅灰棋盘格（保留「透明底」语义），边框用纸面线条色
- 图标框悬停去掉放大 + 蓝色发光（纸面主题静态原则），改为边框 accent 色提示
- 按同类浅色特征全文件排查，确认 `icon-pick` 是唯一漏网点，其余组件均有 calm 覆盖

## 影响范围

- 仅设置页「外观 → 应用图标」卡片与 calm 主题

## 验证

- 浏览器 dev 预览应用图标分区截图：标题、说明、按钮、图标框全部清晰可读
