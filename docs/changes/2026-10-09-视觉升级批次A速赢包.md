## 变更摘要

背景：全量视觉盘点（悬浮球 + 设置窗 × 极光玻璃 / 清爽纸面双主题）后确定 A/B/C/D 四批次升级计划，本批次为 A 组「速赢包」——8 项相互独立的低风险小改。

- **A1 空状态引导可点击**：`ErrorHint` 新增 `actionLabel` + `onAction` 可选 props，action 区渲染为真正的 `<button class="error-hint__button">`（保留原 `action` 文本用法向后兼容）；悬浮球「暂无数据」空状态改为「打开设置」按钮，点击直接 `openSettings()`，从「提示」升级为「引导」。按钮为胶囊描边样式、色随 info/warn/error 三 tone；浮球深底内统一为蓝色系；清爽纸面主题为白底实感 + accent 描边并随 tone 微调文字色。
- **A2 跑马灯死代码清理**：`.included-usage__name-track` / `.included-usage__name-marquee` / `@keyframes includedUsageNameMarquee` 及其 reduced-motion 块全段删除（全仓 grep 确认无任何 TSX 引用）。
- **A3 收起按钮图标化**：header 收起按钮由文本 `×` 改为 `IconClose`（16×16 viewBox、strokeWidth 1.5 双线 SVG），与 IconRefresh / IconSettings 同一线性图标语言；删除 `.btn-icon--close` 中为文本服务的 `font-size: 16px`。
- **A4 红黄绿灯缩小**：`.traffic-light` 17px → 11px（参照 macOS 原生 ~12px，原尺寸在 276px 窄面板中视觉过重），`.floating-ball__brand-row` gap 12px → 10px；极光 / calm 两套灯体 keyframes 为相对值无需改动。
- **A5 深底对比度提升（AA）**：极光主题深色卡片上的 `#6b7280` 二级文字（约 3.2:1，不达 AA）统一提亮为 `#94a3b8`（约 4.7:1）——涉及 `.metric-card__detail`（含面板窄版）、`.dashboard-summary__detail`、`.dashboard-summary__billing-label`、`.meta-time__label`、`.included-usage__date-range`、`.included-usage__hint`、`.metric-row__detail`；`.floating-ball__total-label` 9px → 10px 且 `#aeb9c9` → `#b6c2d2`（calm 主题同步 10px）。unknown 状态填充色与 legacy health-dot 的 `#6b7280` 为状态语义色，保持不变。
- **A6 中文字体显式声明**：body font-family 显式加入 `'Microsoft YaHei UI', 'Microsoft YaHei'`，消除不同 Windows 机器上中文回退字体不一致的渲染差异。
- **A7 Toast 状态化**：toast 由纯文本升级为 tone 语义结构——`showToast(message, tone?: 'ok' | 'error')`（默认 ok）；`ToastTone` 类型从 `SettingsPage.tsx` 导出，`SubscriptionsPage` 17 处调用全部标注（保存/清除类 → ok，不能为空/请先配置/异常 message → error），`SettingsTabContent` 四个组件 `onToast` 签名放宽为 `(message, tone?)` 并透传；渲染层注入 `.settings-toast--{ok|error}` + `.settings-toast__icon`（✓ / ! 圆形徽标），极光主题绿/红双色描边与徽标，纸面主题在墨色 toast 上用提亮变体。
- **A8 `.settings-toast` 重复定义清理**：删除 Page Shell 区（原 ~2974 行）的旧版定义，其属性早已被新版（Toast 区，999px 胶囊版）完全覆盖，属死代码。

## 影响范围
- 悬浮球面板：空状态引导、收起按钮、状态灯、球心小字、二级文字对比度。
- 设置窗口：凭据操作 / 偏好保存的 toast 反馈、error-hint 引导按钮。
- 不涉及数据结构、IPC 与设置项；`ErrorHint` 与 `showToast` 的既有调用方式保持向后兼容。
