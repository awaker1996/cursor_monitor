# 贴边悬浮误触发修复

- 日期：2026-07-07
- 类型：fix
- 关联文件：electron/floatingBallDock.ts、src/renderer/styles.css

## 变更摘要

- 贴边检测改为基于悬浮球锚点矩形（右下角 80×80），不再使用 300×448 整窗边界
- 四边距离增加 `Math.max(0, dist)` 夹取，避免窗口超出 workArea 时负距离误触发贴边
- display 选择改为 `getDisplayNearestPoint`（锚点中心与光标落点均值），替代 `getDisplayMatching(整窗)`
- 修正 `.floating-ball--docked-left` flex 布局，peek 由窗口右上角改为左下角，与左贴边视觉一致

## 影响范围

- 屏幕非右下区域拖拽松手时不再误收起
- 左贴边 peek 正确贴住屏幕左边缘
- 右/底/顶贴边与 undock 交互逻辑不变

## 验证

- `npm run typecheck` 通过
- 左上方/正上方中间区域松手不误触发贴边
- 四边距边缘 < 24px 时正确收起且 peek 贴住对应边缘
- 点击或向外拖出 peek 可恢复
