# EXE 体积优化（第一阶段）

- 日期：2026-07-06
- 类型：build
- 关联文件：package.json, tsconfig.electron.json, electron-builder.yml

## 变更摘要

- 构建链：`build` 改为仅 `vite build`，`dist` 增加 `typecheck` 前置步骤
- 打包范围：`dist-electron/**/*` 收窄为 `main.js` + `preload.js`，排除 `*.map`
- 依赖归类：`react`/`react-dom` 从 dependencies 移至 devDependencies
- TypeScript：`tsconfig.electron.json` 设置 `noEmit: true`、`sourceMap: false`

## 影响范围

- `app.asar` 从 ~6.7 MB 降至 ~1.8 MB（去除 tsc 重复产物与 react 重复打包）
- 便携版 EXE 从 ~74.1 MB 降至 ~73.5 MB
- 功能无变化，nsis + portable 双产物保持不变

## 验证

- `npm run typecheck` 通过
- `npm run dist` 成功产出安装包与便携版
- 应用可正常启动
