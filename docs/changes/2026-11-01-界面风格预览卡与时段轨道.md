# 界面风格：预览卡选择器与昼夜时段轨道

- 日期：2026-11-01
- 类型：feature, style
- 关联文件：`src/renderer/components/StylePicker.tsx`（新增）, `src/renderer/components/SettingsTabContent.tsx`, `src/renderer/uiStyle.ts`, `src/renderer/styles.css`, `README.md`

## 变更摘要

- 界面风格的四档切换由「一条等宽分段控件」改为**两行两列的预览卡**：上排「自动跟随」（跟随系统 / 跟随时间）、下排「手动固定」（清爽纸面 / 极光玻璃），分组标题右侧带一句共性短语与渐隐细线
- 每张卡内用 CSS 画一扇**迷你窗口缩略图**（标题条 + 侧栏 + 内容线，标题条首点为品牌色）：跟随系统是左浅右深的硬分割，跟随时间是浅到深的昼夜渐变，清爽纸面 / 极光玻璃各自还原真实底色与强调色；缩略图不随当前主题变色，四档可以同屏对比
- 选中态改为「描边高亮 + 单选圆环内弹入对勾」，名称与短提示（如「浅色实底 · 高对比」）排在同一行，右侧对勾独立成列，四档的行高与基线对齐
- 切换动效：切到哪一档，哪一档播一次 0.72s 斜向扫光；对勾用 `--ease-spring` 弹入，替代原来整块底色硬跳
- 「当前生效」胶囊改为三段式：呼吸圆点 + 「当前生效」弱化标签 + 名称 + 竖线分隔的原因（系统深色 / 系统浅色 / 时段（含跨零点「次日」）/ 固定深色 / 固定浅色）
- 「跟随时间」的时段子区重排为：太阳月亮图标 + 标题与说明 + 两个「时 : 分」下拉，下方新增一条 **24 小时昼夜轨道** —— 白天段高亮、当前时刻一枚发光刻度、00/06/12/18/24 刻度标尺，跨零点时自动拆成两段
- 交互可达性：整组 `role="radiogroup"` + 每卡 `role="radio"`，方向键 / Home / End 在四项间移动并即时切换，焦点与 `aria-checked` 同步；`prefers-reduced-motion` 下停掉扫光、呼吸环与位移动效
- 窄窗（≤760px）降级：隐藏分组短语、缩略图与内边距收一档、时段下拉落到说明下方独占一行，避免文字折成碎行

## 影响范围

- 新增 `src/renderer/components/StylePicker.tsx`：`StylePicker`（预览卡选择器）与 `DayWindowTrack`（24 小时轨道）两个组件
- `UI_STYLE_OPTIONS` 每项新增 `hint` 字段（卡片内的一行短提示）；`label` / `description` / `group` 语义不变
- `SettingsTabContent.AppearancePrefs` 不再使用 `Segmented`（组件与其样式保留，供其他少量互斥选项复用），新增 `switchedTo` 状态驱动切换扫光；`statusNote` 在手动档下由 `null` 改为「固定深色 / 固定浅色」
- 设置数据与 IPC 不变：仍写 `uiStyle` / `uiStyleDayStartMin` / `uiStyleDayEndMin`，`data-ui-style` 仍只有 `aurora` / `calm`，首帧内联脚本与主进程逻辑未改动
- 样式全部集中在 `styles.css` 的界面风格卡区块，并为 `html[data-ui-style='calm']` 补齐对应的纸面配色；新增 `style-picker` / `style-opt` / `style-mock` / `day-track` 四组类名，旧的 `.segmented--wide` 两条规则删除
