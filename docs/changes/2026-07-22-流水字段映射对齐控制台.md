# 流水字段映射对齐控制台

- 日期：2026-07-22
- 类型：fix
- 关联文件：src/shared/usageFlowFormat.ts、src/core/normalizer.ts、src/shared/types.ts、scripts/verify-usage-flow-format.ts

## 变更摘要

- 修复 Date 列为空：Cursor API 的 `timestamp` 为毫秒数字字符串，`new Date("1750979225854")` 无法解析，改为先转 number
- Type 列：`USAGE_EVENT_KIND_INCLUDED_IN_PRO_PLUS` 等枚举映射为控制台一致的 `Included`
- Cost 列：套餐内 Included 事件显示 `Included`，不再展示内部 `chargedCents` 金额
- 与控制台共用同一端点 `POST /api/dashboard/get-filtered-usage-events`

## 验证

- `npx tsx scripts/verify-usage-flow-format.ts`
- 流水窗 Date 列显示东八区时间，Type/Cost 与 cursor.com/dashboard/usage 一致
