# 设置页「其他」Tab 窄窗自适应修复

- 日期：2026-09-26
- 类型：fix
- 关联文件：src/renderer/styles.css

## 变更摘要

### 问题

当用户缩小设置窗口尺寸时，会触发两类布局问题：

1. **内容互相叠压**：高度被压缩时 **数据刷新** 卡的输入框与脚注互相叠压，文字穿到 input 上；**外观** 卡的「选择图标 / 恢复默认」按钮与脚注叠在一起
2. **核心功能卡内嵌滚动条**：因为它走的是 `grid-template-rows: auto minmax(0, 1fr)` 的 1fr 行 + 自身 `overflow-y: auto`，导致内容超出时只在卡里出现一个小滚动条，用户无法一眼看完全部功能介绍
3. **窄高窗被静默裁剪**（800×480 最小窗口）：body 也不出现滚动条，没法滚下去看下面的卡片

### 根因

1. `.page-shell--settings .settings-section__body` 用了 `flex: 1; min-height: 0`，窗口高度被压缩时 body 会缩到内容高度以下，里面的开关 / 输入框溢出到下方脚注位置，视觉上像「穿」过 input
2. `.page-shell--settings` 用了 CSS Grid 三列 + 1fr 宽卡行，强制 1fr 导致宽卡永远被限定为剩余高度，多余内容只能走卡内滚动
3. 外层 page shell 之前是 `height: 100%; overflow: hidden`，即便在窄宽屏已经把 body 设成 `overflow: auto`，body 也无内容可滚（被 page shell 裁干净了）

### 修复

#### 主体：换掉布局方式

把 3 列 grid + 1fr 宽卡改成 **横向 flex + wrap**：

- `.page-shell--settings`: `display: flex; flex-direction: row; flex-wrap: wrap`
  - 必须显式声明 `flex-direction: row`：基类 `.page-shell` 设的是 `column`，不重置的话子元素仍然竖排
- `.settings-section--tile`: `flex: 1 1 280px; min-width: 0`
  - 默认 3 tile 一行排开；窗口不够 3 tile 时 flex-wrap 自动换行
  - `min-width: 0` 防止内部 input / grid 把卡撑爆
- `.settings-section--wide`: `flex: 1 0 100%`
  - 核心功能卡 `basis: 100%` 始终独占整行，`flex-shrink: 0` 不会被压缩

#### 配套改动

- **取消卡内滚动**：`.project-features` 去掉 `overflow-y: auto`，让所有内容直接渲染出来
- **取消卡内裁剪**：`.settings-section--wide` 去掉 `overflow: hidden` 和 `min-height: 0`
- **body 始终可滚动**：`.settings-page__body:has(.page-shell--settings)` 直接设 `overflow: auto`，不再区分默认 / 窄屏断点（窄宽屏断点 940px 也删了，flex-wrap 已经接管所有自适应）
- **body 不再缩到内容以下**：`.settings-section__body` 把 `min-height: 0` 换成 `min-height: max-content`，杜绝内容溢出脚注位置
- **脚注不参与收缩**：`.settings-section__footnote` 加 `flex-shrink: 0`，确保底部脚注永远完整可见

### 关于早期加的 tile 卡 `overflow: hidden` 兜底

前一轮排查时曾给 `.settings-section--tile` 加过 `overflow: hidden`，实测发现它会反过来把卡片自身的底部脚注也裁掉，反而成了另一个 bug。本次回滚掉这一行，靠上面那些改动就足以保证不叠压。

## 影响范围

- 仅影响设置窗口「其他」Tab 的卡片布局
- 默认 1120×720：3 tile 一行 + 核心功能整行；窗口不够高时整页 body 滚动
- 中等宽度（如 1000px）：3 tile 仍排一行
- 中窄宽度（如 700px）：3 tile 自动换行成 2+1
- 极窄宽度（如 500px）：所有 tile 单列展开
- 任何尺寸下都没有「卡内嵌小滚动条」，核心功能内容通过整页 body 滚动查看

## 验证

- 默认 1120×720：3 tile 一行 + 核心功能整行；所有内容可滚动查看，**无卡内滚动条**

- 700×720：tile 换行 2+1，核心功能整行
- 500×720：所有 tile 单列展开
- 800×480（最小窗口）：所有卡片完整渲染，body 滚动查看全部内容
