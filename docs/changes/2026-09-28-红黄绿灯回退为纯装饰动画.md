# 红黄绿灯回退为纯装饰动画

- 日期：2026-09-28
- 类型：revert
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css、README.md
- 回退对象：同目录 `2026-09-28-红黄绿灯绑定健康状态.md`

## 变更摘要

按反馈回退同日提交的三色灯功能绑定：三色灯恢复为**纯装饰循环动画**，并移除为此引入的全部状态逻辑判断。灯体尺寸沿用当前的 17px 与金属灯位环造型，未做改动。

## 移除的状态逻辑

### App.tsx

- 删除 `TrafficSignal` 类型与 `trafficSignal()` 状态机函数
- `TrafficLights()` 恢复为**无 props** 组件，容器回到固定的 `className="traffic-lights"`、`aria-label="状态指示灯"`，并移除 `title` / 动态 `aria-label`
- 删除组件调用处的 `signal` / `label` / `slowBlink` 三个 props
- 删除派生变量 `lightSignal` 与 `slowBlink`（后者原本读取 `PollerState.failureCount`）
- `healthColor()` 回退为返回 `string`，并恢复原合并写法 `snapshot.stale || backoff → yellow`（backoff 不再单独走红色分支）
- `healthLabel()` 恢复原判断顺序（`stale` 先于 `backoff`）
- 概览卡片 `dashboard-summary__meta` 恢复 `health-pill` 标签

### styles.css

- 删除 `.traffic-lights--{off|ok|fetching|warn|error}` 容器状态类与 `.traffic-lights--slow` 慢闪类
- 删除 `--lamp-color` / `--lamp-glow` 通电色变量
- 删除 `@keyframes trafficLightBreathe` / `trafficLightBlink`
- 恢复 `@keyframes trafficLightCycle{R,Y,G}` 三组循环关键帧与 `animation-delay` 错相位（红 0s → 黄 0.9s → 绿 1.8s，总周期 2.7s）
- `.traffic-light` 恢复 `animation-duration / timing-function / iteration-count`，移除 `transition` 与 `filter`
- 恢复 `prefers-reduced-motion` 下的原处理（`animation: none` + 三灯统一熄灭态 `#16162b`）
- 恢复 `.health-pill` 及 `--green/--yellow/--blue/--gray` 四条配色规则
- 删除 `.floating-ball__orb--health-red` 红档样式块

## 关于悬浮球红档

上一提交曾新增 `.floating-ball__orb--health-red`，其唯一存在理由是让球环与三色灯红灯对同一 backoff 状态显示一致。三色灯回退为装饰动画后已无红色指示器，该红档成为孤立逻辑，故一并移除，`healthColor()` 恢复将 backoff 归入黄色档。

## 恢复后的表现

- 三色灯以 2.7s 周期依次循环点亮（红 → 黄 → 绿），与 `health` / `snapshot` / `pollerState` 完全解耦
- 刷新、切 Tab、故障退避均不影响动画节奏
- 连接健康状态改由概览卡片内的 `health-pill`（正常 / 缓存数据 / 退避中 / 已暂停 / 刷新中）与悬浮球环颜色继续承担
- `prefers-reduced-motion: reduce` 下三灯静止，统一显示熄灭态

## 影响范围

- 弹窗 header 三色灯
- 概览卡片 meta 行（恢复 health-pill）
- 悬浮球环 backoff 配色由红回退为黄
- 不改数据流、不改刷新/设置/收起按钮、不改窗口尺寸与拖拽行为
