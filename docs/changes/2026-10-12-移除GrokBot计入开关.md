## 变更摘要
- 移除设置项 `includeGrokBotUsage`：删除 `AppSettings` 字段、`DEFAULT_SETTINGS` 默认值，以及仅服务于该开关的 `UsageNormalizationOptions` 类型
- `normalizer.ts` 移除贯穿调用链的 `options` 形参与实参（`isExcludedGrokBotModel`、`sumAggregated*/sumEvent*`、`resolveCycleCosts/Tokens`、`aggregateTokenEvents`、`aggregateIncludedUsageByModel/FromAggregations`、`resolveIncludedUsage`、`buildMetricsFromPlan/Overall`、`normalizeCookie`、`normalize`）
- `isExcludedGrokBotModel` 收敛为单参判断，`grok-bot-automation` / `grok-bot-default` **恒定剔除**，不再受开关影响
- `ProviderManager` 删除 `normalizationOptions()` 与对应类型导入，`normalize` 调用不再透传选项
- `electron/main.ts` 删除「切换开关后立即重算并广播」的 IPC 副作用分支
- 设置窗「数据刷新」区由三行减为两行，移除「计入 Grok Bot 用量」开关与其 toast；分区描述文案同步精简
- `mockElectronAPI` 移除对应 mock 默认值
- 两个验证脚本删除 `{ includeGrokBotUsage: true }` 分支用例，保留剔除行为的数值断言
- README 同步：删除「范围内」条目、FR-11 与界面说明中的开关描述、配置项表行、验收项，`数据刷新` 由三行改为两行，文末版本更新为 v1.8

## 影响范围
- `grok-bot-*` 模型始终不计入今日用量百分比与模型明细（等同于原默认行为），行为对普通用户不变，仅不再可配置
- 分区分母语义保持不变：bot 的成本 / token 仍计入 Cursor Models 与 Other Models 的分区分母（`buildIncludedUsageCategory` 的 `denominators`），只从分子与模型列表剔除
- `isAutoModel` 的 `includes('grok')` 保留：IDE 内 `grok-*` 模型（如 `grok-4.5-fast-xhigh`）仍归入 Cursor Models 池
- 老用户 `settings.json` 中的历史 `includeGrokBotUsage` 键在合并时被无害保留，不做迁移
- 设置窗「关于」页功能卡由 README「范围内」清单渲染，同步后不再出现 Grok 条目
