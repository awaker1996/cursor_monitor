# 悬浮球弹窗宽度锁定

- 日期：2026-07-21
- 类型：fix
- 关联文件：electron/windows/floatingBall.ts、electron/floatingBallDock.ts、electron/main.ts、src/renderer/styles.css

## 变更摘要

- 复现：点击悬浮球后弹窗初始为紧凑宽度，运行一段时间后异常变宽
- 根因：历史 `setBounds` 路径（hover 280、贴边/展开宽不一致）会改窗宽；面板又是 `width: 100%`，窗体一漂视觉必漂
- 固化 `ORB_PANEL_WIDTH = 300`，主进程锁定 min/max 宽度并在 resize 时纠偏
- 渲染层面板固定 276px，即使窗体异常变宽也不再被拉伸

## 影响范围

- 悬浮球展开弹窗长期宽度一致性（目标维持初始紧凑宽度）

## 验证

- `npm run typecheck`
- 完全重启（主进程需重载）后对比：刚打开与等待数分钟/多次刷新后的弹窗宽度一致
