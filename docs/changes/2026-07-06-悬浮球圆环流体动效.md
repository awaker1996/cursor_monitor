# 悬浮球圆环流体动效

- 日期：2026-07-06
- 类型：feature
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css

## 变更摘要

- 加深流体视觉：更粗环宽、更强三层 glow、双段高光（主流 + 拖尾）、cap 脉动
- 加快流动速度，渐变对比度提升，linear 往复动画更易感知
- 新增 `orb-ring-flow` 高光弧段，沿余量弧段内往复流动（非整圆旋转）
- 新增 `orb-ring-glow` 外发光层，粗细/透明度随 `--orb-percent` 联动
- `--orb-percent` 驱动流速、环宽、光晕强度、端点 cap 半径
- `clipPath` 裁切渐变与高光，仅作用于已填充余量弧
- 余量变化过渡改为 `cubic-bezier(0.4, 0, 0.2, 1)` 缓动
- 缓存/退避/暂停态（`motion-muted`）及 `prefers-reduced-motion` 下关闭流体动画

## 影响范围

- 仅主悬浮球 orb 圆环视觉，贴边 peek 环不变
- 无 IPC 或数据逻辑改动

## 验证

- `npm run typecheck` 通过
- 高余量：弧内高光快、光晕强、环较粗
- 低余量：弧短、光晕弱、流动慢
- 0% / 无数据：无 flow/glow
- 缓存/退避/暂停态仅静态环
