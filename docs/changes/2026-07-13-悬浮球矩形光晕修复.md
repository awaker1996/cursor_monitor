# 悬浮球矩形光晕修复

- 日期：2026-07-13
- 类型：fix
- 关联文件：src/renderer/styles.css

## 变更摘要

- 根因：悬浮球距透明窗口右/下边缘仅 12px，而其暗色阴影与绿色光晕外扩约 28px，被窗口边界硬裁切成矩形（深色背景上尤为明显）
- 因面板宽 276px 占满 300px 窗口内宽，无法整体加大容器 padding，故改为给 `.floating-ball__orb-wrap` 单独增加右/下外边距，为圆形光晕留出淡出空间
- 贴边（docked/peek）态重置该外边距，保持迷你球紧贴屏幕边缘
- 同时允许圆环 SVG 光效越过自身视口自然衰减

## 影响范围

- 悬浮球圆环及其动态光晕（非贴边态）在窗口内完整淡出，不再出现矩形边界
- 展开面板宽度不变；贴边 peek 行为不变

## 验证

- `npm run typecheck`
- 在深色背景下检查悬浮球边缘，确认无矩形色块且圆形光晕完整
