# 悬浮球动态余量百分比改造

- 日期：2026-07-06
- 类型：feature
- 关联文件：src/shared/format.ts、src/renderer/App.tsx、src/renderer/styles.css

## 变更摘要

- 折叠悬浮球中心文案由「消耗」改为「余量」，数值改为 `totalRemaining / totalLimit` 聚合后的余量百分比
- 新增 SVG 环形进度层，随余量百分比平滑过渡
- 增加呼吸光晕与数值更新脉冲动效，风格对齐 QQ 电脑管家轻量悬浮球
- 健康状态（green/yellow/blue/gray）映射环形主色；stale/退避/暂停时弱化光晕
- 支持 `prefers-reduced-motion` 降级，关闭呼吸与过渡动画

## 影响范围

- 折叠态悬浮球展示语义与数据源余量一致，展开面板「总消耗」逻辑不变
- 无新增 IPC 或主进程改动，拖拽、贴边、展开交互保持原样

## 验证

- `npm run typecheck` 通过
- 无数据、stale 缓存、暂停/退避、正常刷新场景下环形与中心数值可正确展示或兜底为 `--`
