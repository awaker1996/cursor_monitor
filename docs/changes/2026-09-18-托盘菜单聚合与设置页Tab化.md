# 托盘菜单聚合与设置页Tab化

## 日期
2026-09-18

## 类型
feature, refactor

## 关联文件
- `electron/tray.ts` — 托盘菜单精简，移除独立窗口入口
- `electron/main.ts` — IPC 回调重定向到设置窗口
- `electron/windows/settings.ts` — 窗口尺寸扩大，支持 `tab` 参数定位 Tab，隐藏菜单栏
- `settings.html` — body class 改为 `page-settings-tab`
- `src/renderer/pages/SettingsPage.tsx` — 重构为 Tab 布局，移除冗余标题
- `src/renderer/components/TabBar.tsx` — 新建 Tab 切换组件
- `src/renderer/components/SettingsTabContent.tsx` — 从原 SettingsPage 抽取的设置内容
- `src/renderer/components/SubscriptionUtils.ts` — 从 SubscriptionsPage 抽取的工具函数
- `src/renderer/components/SubscriptionPanels.tsx` — 从 SubscriptionsPage 抽取的子组件
- `src/renderer/pages/SubscriptionsPage.tsx` — 精简，引用抽取出的组件
- `src/renderer/styles.css` — 新增 Tab 布局样式，移除多余标题样式

## 变更摘要

### 托盘菜单调整
1. 移除「查看流水」「其他订阅」菜单项，相关功能统一在设置窗口内通过 Tab 切换访问
2. 「应用设置」改名为「设置」，打开设置窗口默认 Tab
3. 「重置悬浮」改名为「复位」（两字）

### 设置窗口清理
1. 窗口标题从「Cursor Token Monitor - 设置」简化为「设置界面」
2. 隐藏原生菜单栏（File / Edit 那一行无意义功能区），通过 `autoHideMenuBar` + `setMenuBarVisibility(false)` 双重移除
3. 移除设置页内的 `<h1>设置</h1>` 标题，TabBar 直接位于窗口顶部

### 设置页 Tab 化
- 设置窗口统一承载三个功能页：流水、订阅、设置，通过顶部 Tab 切换
- 设置窗口尺寸从 520×720 扩大为 1120×720，适配流水表格宽度
- Tab 通过 URL hash 定位（`#flow` / `#subscriptions` / `#settings`），托盘菜单点击对应项时直接打开到目标 Tab
- 窗口已打开时通过 `executeJavaScript` 切换 hash 而非新建窗口

### 代码精简 — 抽组件
- `SubscriptionsPage.tsx`（788→300 行）：工具函数移入 `SubscriptionUtils.ts`，子组件（AccountBadge / UsageLimitRow / CommandCodeAccountPanel / CommandCodeLimitsPanel / DeepSeekBalanceBody）移入 `SubscriptionPanels.tsx`
- `SettingsPage.tsx`（299→40 行）：原设置内容移入 `SettingsTabContent.tsx`，SettingsPage 仅负责 Tab 路由
- 新建 `TabBar.tsx` 通用 Tab 切换组件

## 影响范围
- 托盘右键菜单所有用户可见
- 设置窗口行为变化：原三个独立窗口合并为一个 Tab 窗口
- 悬浮球设置按钮行为不变（仍打开设置窗口）
- `flow.html` / `subscriptions.html` 入口文件保留但不再被窗口加载

- 托盘右键菜单仅包含：设置、复位、退出
- 托盘右键「设置」→ 设置窗口打开，窗口标题显示「设置界面」
- 窗口无 File / Edit 菜单栏
- TabBar 直接位于窗口顶部，下方无多余「设置」标题
- 设置窗口内 Tab 可切换到流水 / 订阅 / 设置
- 托盘右键「复位」→ 悬浮球重置位置和可见性
- Tab 间切换正常，各 Tab 内容功能完整
