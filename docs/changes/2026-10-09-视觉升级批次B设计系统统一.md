## 变更摘要

背景：批次 A 收口了零散问题，本批次做「地基」——把散落在 6700 行样式里的语义色、缓动曲线、时长、圆角、字号收敛成令牌，后续 C/D 批次全部建立在令牌之上。改动集中在单个 CSS 文件，无 TSX / IPC / 数据结构改动。

### B1 语义色令牌

新增**五状态 × 六档**令牌，`:root`（极光玻璃）与 `html[data-ui-style='calm']`（清爽纸面）各定义一套，组件侧只引用不写值：

| 档位 | 用途 |
|---|---|
| `--{state}-fg` | 文字 / 图标 |
| `--{state}-bg` | 实心填充基色（进度条、渐变起点） |
| `--{state}-bg-hi` | 填充高光端（渐变终点） |
| `--{state}-soft` | 浅底（chip / hint 背景） |
| `--{state}-soft-hi` | 图标圆底（比 soft 更实一档） |
| `--{state}-border` | 描边 |

`state` = `ok` / `warn` / `bad` / `info` / `neutral`。另加 orb 健康环专用组 `--ring-{ok|warn|info|neutral}`。

极光侧取值（原散落值收敛）：

| 状态 | fg | bg | bg-hi | border |
|---|---|---|---|---|
| ok | `#4ade80` | `#34d399` | `#4ade80` | `rgba(52,211,153,.36)` |
| warn | `#fbbf24` | `#f59e0b` | `#fbbf24` | `rgba(245,158,11,.38)` |
| bad | `#f87171` | `#ef4444` | `#f87171` | `rgba(239,68,68,.4)` |
| info | `#60a5fa` | `#38bdf8` | `#7dd3fc` | `rgba(96,165,250,.4)` |
| neutral | `#9ca3af` | `#6b7280` | `#94a3b8` | `rgba(148,178,255,.2)` |

纸面侧沿用既有 `--calm-*` 取值（ok `#0b6e3d`/`#0f8a4d`、warn `#8f5406`/`#e0940b`、bad `#a32e2e`/`#d43c3c`、info `#1d4fd8`/`#2f6bde`、neutral `#64748b`/`#94a3b8`），环色沿用原调深值 `#0ea372`/`#d98a06`/`#0284c7`/`#8a97a8`。

**替换范围**（共 40 余处）：`health-pill`、`source-tag`、`metric-card__value/__fill`、`dashboard-summary__fill`、`sub-badge`、`limit-chip`（含 `__fill`）、`account-card__status`、`error-hint` 三 tone、`test-result`、`traffic-light` 点亮态、orb 健康环；顺带收口同族的 `field-error` / `field-success`、`settings-section__status--{ok,warn}`、`set-row__error`、用量区 api/auto 分区数值色。

**收益**：令牌化后 9 组 calm 覆盖块（`health-pill`、`source-tag`、`metric-card__{value,fill}`、`dashboard-summary__fill`、`sub-badge`、`limit-chip`、`account-card__status`、`test-result`、`error-hint` 三 tone）与 4 个 calm 环色块成为冗余，全部删除——**换主题只需换一组令牌值，组件侧零覆盖**。

**顺带修掉的两个可读性问题**（此前 calm 下直接继承了深色主题色值，纸面底上不可读）：
- 用量区 api 分区数值色 `#6ee7b7` → `var(--ok-fg)`，calm 下由浅绿变 `#0b6e3d`
- 用量区 auto 分区数值色 `#93c5fd` → `var(--info-fg)`，calm 下由浅蓝变 `#1d4fd8`

**明确未动**：orb 的 `--glass-1/2/3` 渐变叠色与 `--orb-glow-*` 发光（玻璃调色逻辑独立）；`.settings-toast`（两主题下都是墨色深底 toast，不适用浅底语义色模型）；`.health-dot`（全仓无 TSX 引用，属死代码，建议后续按 A2 方式一并清理）。

### B2 动效令牌

新增三缓动 + 三时长，两窗共用：

```
--ease-out:    cubic-bezier(0.22, 1, 0.36, 1)   出场 / 淡入，收尾极快
--ease-spring: cubic-bezier(0.34, 1.4, 0.5, 1)  带回弹的位移
--ease-smooth: cubic-bezier(0.4, 0, 0.2, 1)     两端减速（进度环、扫光）
--dur-fast: 0.16s   --dur-base: 0.25s   --dur-slow: 0.34s
```

- 11 处 `cubic-bezier(...)` 字面量全部落到令牌：`(0.45,0,0.2,1)` 与 `(0.34,1.56,0.64,1)` 分别就近并入 `--ease-smooth` / `--ease-spring`（轻微变化）。
- `--set-ease`（原 `cubic-bezier(0.32,0.72,0.24,1)`）收敛为 `--ease-out` 别名，设置页 20+ 处引用无需改动。
- 41 条 `transition` 声明中 37 条时长落档：`≤0.18s → fast`、`0.2–0.25s → base`、`0.3–0.34s → slow`；`120ms` / `250ms` 一并归一为秒制令牌。
- 刻意保留：`0.8s` 进度环 `stroke-dashoffset`、`0.6s` 球心 `cx/cy/r`、`0.6–0.8s` 级长动画，以及全部 `@keyframes` 的 `animation` 时长——它们是有意的慢速表达，不属微交互档位。

### B3 圆角 / 字号档位

```
--radius-panel: 12px   --radius-card: 10px   --radius-chip: 8px
--fs-mini: 10px  --fs-caption: 11px  --fs-body: 12px  --fs-title: 13px  --fs-headline: 20px
```

- 圆角 39 处落档：`14/12px → panel`、`11/10/9px → card`、`8/7/6/5px → chip`；`999px`（胶囊）与 `4px`（角标）按计划保留特例；`--set-radius` 由字面量 `14px` 改为 `var(--radius-panel)`。
- 字号 114 处落档：`10 → mini`、`11/11.5 → caption`、`12/12.5 → body`、`13/13.5 → title`、`20 → headline`；`14/15/16/18/22/24px` 为展示型字号（大数值、页面标题），不入档位。

**与原计划的一处偏离（有意为之）**：原计划 `--fs-body: 12.5px` / `--fs-title: 13.5px`，实际改为锚定当前出现最多的一档 `12px` / `13px`。理由——12px 出现 30 次、13px 出现 23 次，而 12.5/13.5 合计仅 9 次；若按原值收敛，悬浮球面板内 30 处 12px 文本会被放大 0.5px，直接威胁 `--orb-panel-height: 402px` 的精确配平。改为锚定主导值后，**悬浮球面板渲染结果与改动前逐像素一致**，402px 配平不受影响，需要肉眼回归的范围只剩设置窗「关于页」正文（12.5 → 12）与两处 13.5px 标题（→ 13）。

## 影响范围
- 全视觉层：两窗 × 双主题的所有语义色、微交互动效时长、圆角与字号。
- 不涉及 TSX、IPC、设置项与数据结构。
- 需肉眼回归的**实际视觉差异**仅限：① 极光绿/黄/红在 chip 与灯珠上的轻微色阶收敛；② calm 下 `limit-chip__fill` 三色由继承极光值改为纸面值（`#22c55e→#0f8a4d`、`#f59e0b→#e0940b`、`#ef4444→#d43c3c`）；③ 用量区 calm 数值色（可读性修复，见 B1）；④ 设置窗关于页正文与两处标题的 0.5px 字号变化。
