# 概览与用量动态玻璃效果

- 日期：2026-09-26
- 类型：feature
- 关联文件：src/renderer/styles.css

## 变更摘要

为悬浮球弹窗「概览」与「用量」两个视图的所有卡片叠加 **动态玻璃质感**：浅色描边 + 顶部细高光线 + 缓慢扫过的光泽带，营造真实玻璃材质的微动效。

### 涉及的卡片

| 卡片 | 视图 | 原样式 | 新增 |
|---|---|---|---|
| `.dashboard-summary` | 概览顶部 | 浅灰半透明 + 0.08 描边 | + 0.1 描边 + 顶部细高光 + 底部暗线 + 流动光泽 |
| `.metric-card` | 概览明细 | 浅灰 0.04 半透明 + 0.04 描边 | + 0.06 描边 + 顶部细高光 + 流动光泽 |
| `.included-usage__block` | 用量区块 | 蓝/绿色调 0.08 + 0.28 描边 | + 顶部细高光 + 流动光泽 |
| `.included-usage__section-head` | 用量子区头 | 蓝/绿色调 0.16 半透明 | + 流动光泽 |
| `.included-usage__entry` | 用量模型行 | 黑 0.18 半透明 | + 流动光泽 |

### 流动光泽实现

每张卡片的 `::before` 伪元素承载光泽带：

```css
.dashboard-summary::before,
.metric-card::before,
.included-usage__block::before,
.included-usage__section-head::before,
.included-usage__entry::before {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  background: linear-gradient(
    105deg,
    transparent 30%,
    rgba(255, 255, 255, 0.12) 50%,
    transparent 70%
  );
  transform: translateX(-100%);
  pointer-events: none;
  z-index: 0;
}
```

### 错相位

光泽带动画 `glassShine` 周期 6-8s，5 张卡片用不同 `animation-delay`：

| 卡片 | 周期 | 延迟 |
|---|---|---|
| `.dashboard-summary` | 6.5s | 0s |
| `.metric-card` | 7s | 0.6s |
| `.included-usage__block` | 8s | 1.2s |
| `.included-usage__section-head` | 7.5s | 1.8s |
| `.included-usage__entry` | 6s | 2.4s |

错相位避免整屏同步扫光，让每个卡片的光泽像独立事件。

### `@keyframes glassShine`

```css
@keyframes glassShine {
  0%, 100% { transform: translateX(-100%); }   /* 光泽带在卡片左侧外 */
  45%      { transform: translateX(100%); }    /* 光泽带扫过到右侧外 */
  55%      { transform: translateX(100%); }    /* 在右侧停留 10% 时间 */
}
```

> 0% → 45% 用 `ease-in-out` 平滑扫过；45% → 55% 停留；55% → 100% 渐隐回起始位置，循环。

### 内容层级

光泽伪元素 `z-index: 0`，卡片内文字/track/detail 等子元素设为 `position: relative; z-index: 1`，确保文字浮在光泽之上、不被遮盖。

涉及到的子元素层级处理：

- `.metric-card__main` / `.metric-card__track` / `.metric-card__detail`
- `.included-usage__block > .included-usage__section-head` / `> .included-usage__models`
- `.included-usage__section-head > *`
- `.included-usage__entry > *`

### 可访问性

`@media (prefers-reduced-motion: reduce)` 下：

- 光泽伪元素 `animation: none`，静止在 `translateX(-100%)`（隐藏态）
- 玻璃质感（描边 / 高光 / 渐变背景）保留
- 视觉风格不丢失

## 实现位置

全部集中在 `src/renderer/styles.css`：

- 新增 `@keyframes glassShine` + 5 个伪元素 `::before` 共享样式
- 在 5 张卡片的规则中追加 `position: relative; overflow: hidden`
- 替换原 `.dashboard-summary` / `.metric-card` / `.included-usage__block` 样式，叠加玻璃描边/高光
- 新增 `prefers-reduced-motion` 关闭光泽动画

## 影响范围

- 仅悬浮球弹窗「概览」与「用量」视图的卡片视觉
- 不改数据、不改交互、不改窗口尺寸
- 不影响健康 pill、悬浮球环、红黄绿灯等其它视觉元素

## 验证

- `npm run typecheck`
- 打开弹窗「概览」：总消耗卡片 + 4 张 metric-card 上有缓慢扫过的白色光泽带
- 切换「用量」：每个 included-usage__block 及其内部 section-head / entry 都有错相位的扫光
- 卡片内的文字、百分比、tokens、徽章等正常显示不被光泽遮挡
- 系统开启「减少动态效果」后光泽消失，卡片保留玻璃质感（描边 + 高光线）
