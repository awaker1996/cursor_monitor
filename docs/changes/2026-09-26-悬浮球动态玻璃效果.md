# 悬浮球动态玻璃效果

- 日期：2026-09-26
- 类型：feature
- 关联文件：src/renderer/styles.css

## 变更摘要

悬浮球本体原本只有单一静态渐变背景，本次叠加 **动态玻璃质感**：球面高光（静态）+ 蓝/绿彩色光斑（动态漂移），与下方弹窗卡片的玻璃风格保持一致。

## 三层视觉叠加

### 第一层：底层渐变（保留原风格）

```css
background:
  radial-gradient(
    circle at 32% 28%,
    rgba(255, 255, 255, 0.22) 0%,
    rgba(255, 255, 255, 0.05) 30%,
    transparent 55%
  ),
  linear-gradient(135deg, #1a1a2e 0%, #16213e 100%);
```

- 球面高光（左上角 32%/28% 位置）
- 原有的对角线深蓝紫渐变

### 第二层：动态彩色光斑（`::before` 伪元素）

```css
.floating-ball__orb::before {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: 50%;
  background:
    radial-gradient(
      circle at 75% 30%,
      rgba(96, 165, 250, 0.45) 0%,
      transparent 45%
    ),
    radial-gradient(
      circle at 25% 80%,
      rgba(74, 222, 128, 0.28) 0%,
      transparent 45%
    );
  background-size: 200% 200%, 200% 200%;
  background-position: 0% 0%, 100% 100%;
  pointer-events: none;
  z-index: 0;
  animation: orbGlassDrift 7s ease-in-out infinite;
}

@keyframes orbGlassDrift {
  0%, 100% { background-position: 0% 0%, 100% 100%; }
  50%      { background-position: 100% 100%, 0% 0%; }
}
```

- 蓝色光斑：右上角 → 漂移到左下角
- 绿色光斑：左下角 → 漂移到右上角
- 周期 7s，两层光斑交叉移动，营造"球体内部玻璃液流动"的视觉效果

### 第三层：边框玻璃描边

- `border: 2px solid rgba(255, 255, 255, 0.18)`（从 0.15 微调到 0.18，玻璃描边更明显）

## 元素层级

为了避免光斑挡住进度环 SVG 和中心数字，给关键子元素加 z-index：

| 元素 | z-index | 用途 |
|---|---|---|
| `.floating-ball__orb::before` | 0 | 光斑底层 |
| `.floating-ball__orb-ring` | 1 | 进度环 SVG 在光斑之上 |
| `.floating-ball__orb-core` | 2 | 中心数字在最上层 |

## 动画兼容

- 保留 `orbBreathe` 投影呼吸动画（box-shadow 控制的 glow 效果）
- 新增 `orbGlassDrift` 背景光斑漂移（background-position 控制）
- 两者作用于不同 CSS 属性，互不冲突

## 可访问性

`@media (prefers-reduced-motion: reduce)` 下：

- `.floating-ball__orb::before` 关闭光斑动画，停在 50%/50% 静态位置
- 玻璃质感本身（球面高光 + 蓝/绿光斑 + 描边）保留
- 视觉风格不丢失

## 实现位置

全部在 `src/renderer/styles.css`：

- `.floating-ball__orb`：背景叠加 + 玻璃描边
- `.floating-ball__orb::before`：动态彩色光斑
- `@keyframes orbGlassDrift`：漂移动画
- `.floating-ball__orb-ring` / `.floating-ball__orb-core`：z-index 层级
- `@media (prefers-reduced-motion: reduce)`：关闭动画但保留静态光斑

## 影响范围

- 仅悬浮球本体的视觉
- 不改交互（拖拽、点击、悬停缩放都保留）
- 不影响其它视觉元素

- 进度环 SVG 与中心数字正常显示，不被光斑遮挡
