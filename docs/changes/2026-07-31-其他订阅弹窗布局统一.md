# 其他订阅弹窗布局统一

- 日期：2026-07-31
- 类型：refactor
- 关联文件：src/renderer/pages/SubscriptionsPage.tsx、src/renderer/styles.css

## 变更摘要

- 重构"其他订阅"弹窗布局，消除"API Key 配置 / 余额查询 / 用量 Token 配置 / 用量查询"四段堆叠的割裂感，合并为两张卡片
- 新增"订阅概览"统一卡片：顶部工具栏（月份选择器 + 单个刷新按钮），一次刷新并行拉取余额与当月用量（`Promise.all`）；余额区以状态徽标 + 大字金额（充值/赠送明细小字）展示，用量区保留按模型表格与总 Token/总请求数汇总；两区以虚线分隔置于同一卡片内
- 新增"凭据配置"可折叠卡片：API Key 与用量 Token 集中管理，标题行常显两类凭据的已配置/未配置状态；凭据齐全时默认收起，缺失时默认展开；未配置 API Key 点刷新会自动展开并提示
- 打开弹窗时若 API Key 已配置则自动拉取数据；保存任一凭据成功后自动触发一次刷新
- 错误提示改为分区内联样式（`subscription-inline-error`），余额与用量互不影响；查询时间统一显示在工具栏下方
- 样式同步：新增概览工具栏、分区块、状态徽标、余额大字、折叠开关等 `subscription-` 前缀类；用量表格背景由半透明白改为浅灰底加边框以适配白色卡片

## 影响范围

- 仅"其他订阅"弹窗渲染层布局与交互（IPC、核心层、凭据存储均不变）
- 设置页、流水页、悬浮球等其他窗口不受影响

## 验证

- `npm run typecheck` 通过（electron 与 renderer 两套 tsconfig）
- `npm run build` 通过，subscriptions chunk 正常产出
- 人工验证（待用户执行）：打开弹窗自动加载余额与用量；单个刷新按钮同时更新两块数据；凭据齐全时配置区默认收起、点击标题可展开；未配置时默认展开并有引导提示
