## 变更摘要

- 「外观」分区 Segmented 的风格 label `Aurora 玻璃` → `极光玻璃`，纯中文命名，去掉中英混排
- 切换后的 toast 文案同步（`SettingsTabContent.tsx`：`已切换到 Aurora 玻璃` → `已切换到极光玻璃`）
- README 全量同步（简介、特性清单、设置窗口「外观」区、风格卡片说明、设置项表、v1 范围清单）
- 技术标识 `UiStyle = 'aurora'`、`<html data-ui-style="aurora">`、CSS 类名与 `pageAuroraDrift` 等内部命名一律不动，仅改面向用户的显示文案

## 影响范围

- 设置页「外观」分区的界面风格名称与切换提示；README 文档表述
- 不改持久化配置键、不改样式生效逻辑
