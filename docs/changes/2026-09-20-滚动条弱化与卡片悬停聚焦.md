# 滚动条弱化与卡片悬停聚焦

## 日期
2026-09-20

## 类型
feature

## 关联文件
- `src/renderer/styles.css` — 全局滚动条默认样式；「其他」Tab 卡片悬停与聚焦样式

## 变更摘要

### 全局滚动条弱化
1. 新增全局默认样式：宽/高 8px、轨道与转角透明、隐藏滚动按钮、拇指 `rgba(148, 163, 184, 0.35)` 圆角胶囊，悬停时加深到 0.6
2. 用 `*` 选择器作为默认值（特异性最低），悬浮球内既有的两处深色滚动条（`.included-usage__body`、`.included-usage__table-wrap`，6px + 白色拇指）按特异性继续生效，未被覆盖
3. 同时声明 `scrollbar-width: thin` / `scrollbar-color`，与项目既有写法保持一致：Electron 28（Chromium 120）尚不支持这两个属性，实际由 `::-webkit-scrollbar` 生效；日后升级内核会自动接上且观感一致

### 卡片悬停 / 聚焦
1. 悬停卡片：描边变 `#bfdbfe`（与 `settings-section--primary` 同色）+ 柔和投影 `0 6px 18px rgba(15, 23, 42, 0.09)` + 上移 2px
2. 未悬停卡片压暗到 `opacity: 0.5`，把视觉焦点交给当前卡片
3. 用 `:has()` 判定「是否有卡片被悬停」：`.page-shell--settings:has(.settings-section:hover) .settings-section:not(:hover)`。若改用「父级 hover」写法，鼠标停在卡片之间的空隙时会让所有卡片一起变暗
4. `prefers-reduced-motion: reduce` 下取消位移，仅保留淡入淡出

## 影响范围
- 滚动条：影响渲染层全部滚动区域（设置窗口、流水页、订阅页、悬浮球说明列表）；悬浮球深色区域观感不变
- 悬停效果：仅作用于「其他」Tab。刻意不覆盖「订阅」Tab——该页是长滚动列表，鼠标划过时整页卡片反复明暗闪动会干扰阅读
- 无布局尺寸变化：`transform` / `opacity` 不参与网格计算

## 验证
- 静态截图无法移动指针，改用临时壳页在 CSSOM 层把样式表中真实的 `:hover` 规则重定向为类名并手动挂载，从而渲染出**真实声明值**核对：
  - 被悬停卡高亮抬升、其余三张压暗，核心功能卡右侧内部滚动条呈细淡灰色胶囊
  - 据此把压暗值由 0.45 调为 0.5（0.45 时提示文字过淡）
- 选择器链路（`:hover` / `:has()`）为静态验证盲区，需在应用内实际移动鼠标确认；Chromium 120 已支持 `:has()`
- 人工验证（待用户执行）：鼠标移入/移出各卡片，确认聚焦效果；滚动任意列表确认滚动条为细淡样式
