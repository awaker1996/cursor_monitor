## 变更摘要

- 「智能体」Tab 在本机始终无数据、且需读取 Cursor 10GB 级 `state.vscdb`（单次解析约 5s、常驻高内存）与 `better-sqlite3` 原生依赖，投入产出比低，整体下线该功能。
- 设置窗口恢复为「订阅 / 流水 / 其他」三分区，默认落在「订阅」；托盘「设置」入口不带 tab 参数，仍由 `resolveInitialTab()` 兜底到订阅。
- 主进程不再启动 2s trace 轮询 watcher，不再向设置窗口推送 `agent-trace-updated`；相关 IPC 通道与共享类型一并删除。
- 清理期间产生的临时排查脚本（`scripts/_probe*.cjs`、`scripts/_run-service.*`）一并删除。

## 影响范围

- 用户可见：设置窗口顶部不再出现「智能体」；默认分区由「智能体」变为「订阅」；其余分区与悬浮球功能不受影响。
- 包大小：移除 `better-sqlite3` 11.3.0 Windows x64 prebuilt 及其类型包，安装包与 `node_modules` 相应减小。
- 行为：主进程启动/退出不再创建、销毁 `AgentTraceService`；不再只读打开本机 Cursor 数据库。
- 历史归档 `docs/changes/2026-09-26-设置页智能体Tab与标题简化.md` 保留，作为该功能曾存在的记录。
