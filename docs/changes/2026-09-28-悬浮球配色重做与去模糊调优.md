# 悬浮球配色重做与去模糊调优

- 日期：2026-09-28
- 类型：refactor, feature
- 关联文件：src/renderer/styles.css
- 前序：[[2026-09-28-悬浮球动态玻璃重设计]]（同日第一轮，本篇为其调优）

## 变更摘要

在液态玻璃重设计之后做两件事：**重做四种健康状态的配色取值**，以及**消除悬浮球给人「糊成一团」的观感**。

## 一、配色：同色系收敛

原配色每种状态都跨色系取色（绿配天蓝、黄配暖白），在小尺寸下显得杂乱。改为每态只用
**「主色 + 同色系辅色 + 同族高光」**，色相跨度控制在 45° 以内。

| 状态 | 主色（进度环） | 辅色 | 同族高光 | 色相跨度 |
|---|---|---|---|---|
| 绿 · 余量充足 | `#34d399` 翠绿 | `rgba(45,212,191,.30)` 青 | `rgba(153,246,228,.20)` 薄荷 | 158°–174° |
| 黄 · 陈旧/backoff | `#f59e0b` 琥珀 | `rgba(251,146,60,.28)` 橙 | `rgba(253,230,138,.18)` 浅金 | 27°–45° |
| 蓝 · 刷新中/暂停 | `#38bdf8` 天蓝 | `rgba(99,102,241,.28)` 靛 | `rgba(165,243,252,.18)` 青 | 189°–239° |
| 灰 · 无数据 | `#94a3b8` 石板 | `rgba(148,163,184,.20)` 银 | `rgba(203,213,225,.12)` 灰白 | 低彩度 |

同时把 `--orb-ring-color` 从旧的 `#4ade80` / `#fbbf24` / `#60a5fa` / `#9ca3af`
统一到与玻璃主色同源，四层（环 / 外发光 / 光斑 / 底座）现在是一套色。

灰色态额外整体压暗并降低彩度，视觉上明确「后退」，与有数据状态拉开距离。

## 二、去模糊：全面收敛四层光晕

### 病灶

球体里叠了四层大范围模糊，层层外溢后糊成发光棉花：

| 位置 | 原值 |
|---|---|
| 进度环 glow | `blur(3px)` + `8.5px` 宽描边 + `drop-shadow` 10px / 18px |
| 进度环 progress | 三层 `drop-shadow`：**5px / 14px / 22px** |
| 流光段 / 端点 cap | 各三层 `drop-shadow`：4px / 8px / 14px |
| 球体外发光 | 呼吸 6px → 14px |

其中 22px 的 `drop-shadow` 已超过球体半径（28px 的一半），实际上糊住了整个球。

### 收敛后

| 位置 | 新值 |
|---|---|
| 进度环 glow | `blur(1.5px)` + `+2.5px` 宽描边 + `drop-shadow` 4px / 7px |
| 进度环 progress | 两层 `drop-shadow`：**2px / 5px** |
| 流光段 / 端点 cap | 两层 `drop-shadow`：**2px / 4px** |
| 流光拖尾 | `blur(0.5px)`、`drop-shadow` 3px、宽度 `+1.2px`、透明度 .4 |
| 球体外发光 | 呼吸 4px → 8px（并保留 `--orb-percent` 联动） |

### 让球变「实」而非只是变「淡」

单纯缩小光晕只会让球变暗变闷，因此同时补了三层**结构**：

1. **锐利内环**：投影栈新增 `inset 0 0 0 1px rgba(255,255,255,.12/.2)`，
   呼吸时内环亮度一起起伏 —— 这是硬边玻璃质感的主要来源。
2. **右下暗部**：基底背景新增
   `radial-gradient(circle at 68% 76%, rgba(0,0,0,.5), transparent 52%)`，
   给球体明暗过渡与体积感，避免整球平光。
3. **紧致镜面高光**：原高光 `rgba(255,255,255,.30) → 34% → 58%` 覆盖大半球面，
   是「泛白糊感」的主因；收小为 `34% → 14% → 34%`，只剩一小块高光。

另外：

- 扫掠带由 16% 宽、峰值 `.30` 收窄到 **12% 宽、峰值 `.22`**
- 三片光斑的渐变衰减由 `46%/44%/42%` 收紧到 **`36%/34%/32%`**，色块边界更明确
- 数字底座不透明度 `rgba(8,11,22,.42)` → **`rgba(7,10,20,.54)`**，
  与周围玻璃拉开层次；内高光同样收小
- 进度环底轨 `rgba(255,255,255,.14)` → **`.18`**，空环状态也有明确边界
- 描边 `rgba(255,255,255,.22)` → **`.24`**

## 保持不变

- 球体直径 56px、`ORB_VISUAL_SIZE` 常量、`App.tsx`、进度环几何（r=24 / core 44px）
- 玻璃动效结构：`orbBlobDrift` 三片光斑各走独立路径、`orbSheenSweep` 扫掠带
- 五项状态联动：悬停 / 按下 / 面板展开减速 / 数据静默 / 贴边停摆 / 减少动态
- 不引入 `backdrop-filter`（透明窗口残影历史）、`filter: blur()` 仅保留在
  进度环 glow 与流光拖尾两处小半径用法

## 影响范围

- 仅悬浮球本体的配色与光影
- 不改交互、不改面板/托盘/设置页、不改主进程
