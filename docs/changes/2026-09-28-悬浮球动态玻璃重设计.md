# 悬浮球动态玻璃重设计

- 日期：2026-09-28
- 类型：feature, refactor
- 关联文件：src/renderer/styles.css

## 变更摘要

悬浮球（2026-09-26 已加过一轮动态玻璃）本次做「现代液态玻璃」重设计。

### 根因：上一版玻璃之所以「不明显」

不是光斑太弱，而是**被挡住了**——球体 56px，中心数字底座 `.floating-ball__orb-core` 是一个
**完全不透明**的 44px 实心圆且层级高于光斑层，玻璃实际只剩 6px 宽的圆环可见。

因此本次的核心动作是：**把 orb-core 改成半透明玻璃底座**，让光斑真正透上来。

## 图层栈（自下而上）

| z-index | 图层 | 载体 | 内容 | 动画 |
|---|---|---|---|---|
| — | 基底 | `.floating-ball__orb` background | 左上球面高光 + 三段式深蓝底 | 静态 |
| 0 | 彩色光斑 | `::before` | 3 片径向光斑，颜色取 `--glass-1/2/3` | `orbBlobDrift` ~16s |
| 0 | 高光扫掠 | `::after` | 斜向亮带，超出球体由 `overflow:hidden` 裁切 | `orbSheenSweep` ~7s |
| 1 | 进度环 | `<svg>` | 现状不动 | 现状不动 |
| 2 | 数字底座 | `.floating-ball__orb-core` | **由不透明改为半透明玻璃** | 静态 |
| — | 边缘光 | orb 的 inset box-shadow | 顶部 1px 高光 + 底部内阴影 + 外发光 | `orbBreathe` |

### 1. 三片光斑各走各的路径

`orbBlobDrift` 用 5 个关键帧让三层光斑沿**不同轨迹**漂移，避免整球同步平移的廉价感。
柔化完全交给径向渐变自身的 falloff，**不使用 `filter: blur()`**（避免每帧重绘，
也避开透明窗口上 filter 的历史坑）。

### 2. 高光扫掠层（`::after` 此前未使用）

斜向亮带故意 `inset: -45%` 超出球体，由 orb 的 `overflow:hidden` 裁成圆形；
两端做淡入淡出，避免扫掠带闪现。视觉语言与弹窗卡片的 `glassShine` 一致，
保持全应用玻璃语汇统一。

### 3. 投影栈收敛为变量

整条投影栈收敛为 `--orb-shadow-a` / `--orb-shadow-b`，`orbBreathe` 直接引用，
不必在每个关键帧里重复书写四条 box-shadow。

### 4. 健康态玻璃调色板

玻璃配色跟随健康状态，与进度环、状态圆点语义统一：

| 状态 | 主光斑 | 次光斑 | 边缘反光 |
|---|---|---|---|
| `--health-green` | 翠绿 | 天蓝 | 黄绿 |
| `--health-yellow` | 琥珀 | 橙 | 暖白 |
| `--health-blue` | 天青 | 靛 | 冷白 |
| `--health-gray` | 石板（整体降饱和） | 浅灰 | 灰白 |

### 5. 文字可读性补偿

底座变半透明后，9px / 12px 小字必须补对比度：label 由 `#9ca3af` 提至 `#aeb9c9`，
value 由 `#e0e0e0` 提至 `#f2f6fb`，两者均加 `text-shadow`。

## 状态联动与性能守卫

| 场景 | 行为 |
|---|---|
| 悬停 | 放大到 1.06、描边提亮、外发光切到加亮档 `--orb-glow-color-hi` |
| 按下 | 缩小到 0.98，补按压反馈 |
| 面板展开 | `--glass-speed: 1.8`，玻璃层减速让位读数 |
| 数据静默 | `--glass-speed: 2.4` + 光斑层 `opacity: .6` |
| 贴边 peek | 光斑与扫掠带全部停摆 |
| 减少动态效果 | 所有玻璃动画停止，光斑停在 50% 的静态构图、扫掠带隐藏，**玻璃质感本身保留** |

性能边界：仅动画 `background-position` / `transform` / `opacity` / `box-shadow`；
不加 `will-change`（常驻透明窗口上反而占内存）；不用 `mix-blend-mode`；**不使用 `backdrop-filter`**
（2026-07-06 已因透明窗口下块状残影在明细面板移除过）。

## 硬约束（保持不变）

- 球体直径恒为 **56px**，与 `ORB_VISUAL_SIZE` 一致，否则贴边半隐位移全部错位
- **不改 `App.tsx`**：`ORB_RING_RADIUS = 24`、`viewBox="0 0 56 56"`、core 44px 全部保持
- `.floating-ball__orb` 元素上只保留 `orbBreathe` 一个动画 —— `--motion-muted` 的
  `animation-duration: 5.5s` 是单值简写，会给该元素上**所有**动画统一改时长，
  因此新动效必须放在伪元素上

## 顺带修掉的三个现存问题

1. **z-index 规则自相矛盾**：原 L203 设 `orb-core { z-index: 2 }`、L363 又设 `z-index: 1`，
   后者生效。现统一为「底座的权威声明只在 `.floating-ball__orb-core` 一处」。
2. **贴边 peek 时光斑仍在动**：原 dock 规则只命中 `.floating-ball__orb` 元素本身、
   漏掉伪元素，半隐状态下白白每帧重绘。现补齐 `::before` / `::after` 的停摆。
3. **`--motion-muted` 的 `--orb-glow-color` 自引用**：该声明用 `color-mix` 引用自身，
   属循环依赖会被浏览器丢弃、实际从未生效。**本次未改动它**（不在本次范围），
   仅在此记录；改用光斑层 `opacity` 实现压暗。

## 影响范围

- 仅悬浮球本体的视觉与动效
- 不改交互：拖拽、点击展开/收起、贴边 undock、鼠标穿透判定均照常
- 不影响弹窗面板、托盘、设置页
- 不改 Electron 主进程与窗口尺寸常量
