# 弹窗顶部红黄绿灯动画

- 日期：2026-09-26
- 类型：feature
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css

## 变更摘要

弹窗顶部原本固定显示「Cursor 用量监控」文案，现改为 **红黄绿三色状态灯**，模拟真实横向红绿灯造型：与面板同色系的玻璃外壳 + 三个凹陷灯位 + 立体玻璃灯罩。作为纯装饰性循环动画运行，与健康状态/用量数据完全解耦。

经过两轮迭代：

1. **第一版**：3D 浮雕外壳（深黑塑料 + 多层投影）
2. **第二版**：灯位黑色环 + 玻璃质感强化
3. **第三版（当前）**：外壳改为面板同色系浅灰白半透明 + 灯罩改为深蓝紫 `#16162b`，与 `.dashboard-summary` / `.metric-card` 风格一致

### 外壳（与面板风格统一）

- 横向矩形，`padding: 5px 11px`，圆角 9px
- **极淡叠加背景**：`rgba(255,255,255,0.03)`（在深蓝紫面板上几乎透明）
- **极淡描边**：`1px solid rgba(255,255,255,0.07)`，只保留"灯箱边界"线索不抢戏
- **凹陷感阴影**：
  - `inset 0 1px 0 rgba(255,255,255,0.1)` 顶部细高光
  - `inset 0 -1px 0 rgba(0,0,0,0.18)` 底部暗线
  - 模拟"面板里挖出来的灯位凹槽"效果

**外壳演进（避免抢戏的迭代）**

| 版本 | 背景 | 描边 | 视觉问题 |
|---|---|---|---|
| 第一版 | 深黑塑料四段渐变 `#454545→#0a0a0a` | 1px 双色硬边 | 在深蓝紫面板上"跳出来"，突兀 |
| 第二版 | 浅灰白三段 `rgba(255,255,255,0.08→0.05)` | `rgba(255,255,255,0.1)` | 浅叠加让灯箱在深色面板上显得"过亮" |
| **当前版** | **极淡 `rgba(255,255,255,0.03)`** | **`rgba(255,255,255,0.07)`** | **与面板几乎同色，仅靠极淡描边+凹陷阴影显示"灯箱"** |

### 灯罩（与面板背景同色系）

- 直径 13px，圆形
- **默认熄灭态**：背景 `#16162b`（与面板背景 `rgba(22, 22, 40, 0.98)` 几乎同色），左上角径向高光
- **金属灯位环**：1px `rgba(0,0,0,0.6)`，比第一版的 1.5px `#050505` 更克制，但依然保留"嵌"在外壳里的金属圈感
- **玻璃罩**：`inset 0 1px 2px` 顶部凹陷 + `inset 0 -1px 1px` 底部反光 + `inset 0 0 0 1px` 玻璃边

### 点亮时（保留灯位金属环 + 弱化外发光）

- 实色背景：`#ef4444` / `#f59e0b` / `#22c55e`
- 加强左上角高光（径向 0.55 → 0.2 → 透明）
- **金属灯位环保留**（物理边缘不会因通电消失）
- 外发光（比第一版弱，与面板整体协调）：
  - 5px 近光晕（rgba 0.65）
  - 12px 远光晕（rgba 0.35）
- `transform: scale(1.05)` 微放大

### 动画节奏

- **总周期**：2.7s，三盏灯依次循环切换
- **错相位**：红灯 0s 起跑 → 黄灯 0.9s 起跑 → 绿灯 1.8s 起跑
- **每盏灯的呼吸曲线**：0% 熄灭（scale 0.95）→ 10% 微亮（scale 0.98）→ 18% 峰值（scale 1.05）→ 28% 微亮 → 100% 熄灭

### 与健康状态的关系

**无关**。本动画仅为视觉装饰，不携带任何状态含义。健康状态仍由 `health-pill`（"正常 / 缓存数据 / 退避中 / 已暂停 / 刷新中"）和悬浮球环颜色承担。

## 交互细节

- 外壳 + 三盏灯作为一个整体嵌入 header，宽度由内容自然撑开
- 灯之间的"通电"切换通过 `animation-delay` 错相位实现，避免状态分支
- `prefers-reduced-motion: reduce` 下完全关闭动画，外壳和灯罩保留静态造型（灯统一显示熄灭态 `#16162b`）

## 可访问性

- 容器 `role="status"` + `aria-label="状态指示灯"`（声明性，不携带实时含义）
- 三颗灯本身 `aria-hidden`，避免冗余朗读

## 实现位置

- `TrafficLights()` 内嵌组件，**无 props**，与 `health` / `danger` / `snapshot` 完全解耦
- 头部用法：`<TrafficLights />`
- 样式：`.traffic-lights`（与面板同色系外壳）、`.traffic-light`（金属灯位环 + 玻璃罩）、`.traffic-light--red/yellow/green` 与三组 `@keyframes trafficLightCycle{R,Y,G}`

## 影响范围

- 仅影响悬浮球弹窗顶部 header 区域
- 不改数据流、不改交互（拖拽手柄、刷新/设置/收起按钮位置不变）
- 不影响 `health-pill`、悬浮球环颜色等其他视觉状态指示

## 验证

- `npm run typecheck`
- 打开弹窗：灯箱外壳与面板背景色调一致，不再"跳"出来；金属灯圈细节保留
- 三盏灯依次通电点亮（红 → 黄 → 绿），外发光与面板其它发光元素（如刷新电流边框、健康 pill）强度相当
- 切换「概览 / 用量」Tab 或刷新数据：动画节奏不变（证明与状态完全解耦）
- 系统开启「减少动态效果」后外壳保留浅灰白半透明质感，三灯静态显示熄灭态 `#16162b`
- `health-pill` 仍按预期切换文案（"正常 / 缓存数据 / 退避中 / 已暂停 / 刷新中"），与三灯无联动
