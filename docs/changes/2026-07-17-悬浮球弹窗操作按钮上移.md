# 悬浮球弹窗操作按钮上移

- 日期：2026-07-17
- 类型：feature
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css

## 变更摘要

- 将悬浮球弹窗底部的「刷新」「设置」文字按钮移除
- 在「Cursor 用量」标题栏右侧新增标准小图标按钮：刷新、设置、收起
- 新增 `.floating-ball__header-actions` 与 `.btn-icon--toolbar` 样式，统一 24×24 点击区域与 hover 反馈

## 影响范围

- 悬浮球展开面板顶部操作区布局
- 底部不再占用额外按钮区域，长内容滚动时操作入口始终可见

## 验证

- `npm run typecheck`
- 展开悬浮球弹窗，确认标题栏右侧显示刷新/设置/收起图标，点击功能正常
