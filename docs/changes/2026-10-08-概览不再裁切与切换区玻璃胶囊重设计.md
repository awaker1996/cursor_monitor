# 概览不再裁切与切换区玻璃胶囊重设计

## 日期
2026-10-08

## 类型
fix, feature, refactor

## 关联文件
- `src/renderer/App.tsx`
- `src/renderer/styles.css`

## 变更摘要
- 修复概览视图最后一张卡片与切换区之间间距过大：将面板高度 `--orb-panel-height` 收紧，并把概览视图的切换区由 `margin-top: auto` 改为固定 `margin-top: 8px`，让切换区紧贴内容，不再被顶到底部留下大片空隙。
- 精确配平概览高度，彻底消除滚动：实测此前 body 内容（297.75px）比 body 可视高度（293px）多出约 4.75px，导致鼠标滚轮仍能滚动。改为：面板高度 `--orb-panel-height: 402px`；概览 body 设为纵向 flex 且 `overflow: hidden`（不可滚动）；`.metric-list` 设 `flex: 1`、卡片间距 6px、四张卡片 `flex: 1` 等分填满。配平结果：面板内容区 376px = header 30 + body 307 + 切换区（margin 8 + 高 31）；body 307 = 总览卡 82 + 间距 8 + 指标列表 217；列表 217 = 4 × 49.75 卡片 + 3 × 6 间距，正好填满、零溢出、零留白。
- 面板 402px 仍在既有窗口内：面板帧 `max-height: calc(100% - 108px) = 416px`，且面板 + 球体区域（402 + 8 + 100）+ 外壳内边距 24 = 534 ≤ 窗口高 548，因此窗口高度 `ORB_EXPANDED_HEIGHT` 无需改动。
- 「概览 / 用量」切换改为动态玻璃胶囊：凹陷玻璃槽 + 可平滑滑移的玻璃胶囊（斜向高光渐变 + 顶部内高光 + 边缘细描边 + 蓝色外发光），胶囊内一道柔光周期性掠过（`switchThumbShine`），呼应面板卡片的玻璃扫光语汇。
- 胶囊滑移动画：`transform: translateX(0 → 100%)`，`0.34s cubic-bezier(0.34, 1.4, 0.5, 1)`（带轻微回弹）；`prefers-reduced-motion` 下瞬移并停掉扫光，玻璃质感保留。
- 清爽纸面主题：胶囊改为白卡实底 + 细描边 + 轻投影，去光晕与扫光；槽底为浅灰内阴影。
- 修复清爽纸面主题下用量视图滚动条不可见：极光基底用白色半透明滑块，浅底上不可见；为 `html[data-ui-style='calm']` 下的 `.included-usage__body` 增加中性灰滚动条覆盖（`scrollbar-color` 与 `::-webkit-scrollbar-thumb`）。
- 修复「概览 ↔ 用量」切换时切换控件尺寸跳变：此前概览用 `padding-top: 0`、用量用 `padding-top: 6px` 且 `margin-top: auto`，导致容器高度在 28px / 34px 间变化。统一为单条规则（`margin-top: 8px; padding: 3px`），删除两处视图专属覆盖，两视图下控件几何完全一致（31px）。
- 重设计清爽纸面主题的切换背景：底槽改为中性浅灰凹槽（细描边 + 内阴影 + 白色内描边），选中胶囊用白→浅蓝渐变 + 品牌蓝描边 + 柔和蓝色投影，形成清晰、有品牌感的「选中」层级，替换此前与底槽对比过弱的浅灰底 + 白胶囊方案。

## 影响范围
- 悬浮球详情面板（概览视图、用量视图）的布局高度与切换控件外观。
- 悬浮球窗口展开高度保持不变（`ORB_EXPANDED_HEIGHT = 548`），仅面板高度按内容收紧。
- 不涉及数据结构、IPC 与设置项。

## 验证
- `npm run typecheck` 通过
- `npx vite build` 通过
- 浏览器预览（aurora 与 calm 两主题）实测：概览 body 高 307px = 内容高 307px，`overflow: hidden`，滚轮无法滚动；四张卡片各 49.75px、间距 6px、零留白；切换区 31px 且两视图一致；用量视图滚动条在纸面主题下清晰可见。
