# 界面风格自动切换与按钮换位

- 日期：2026-10-25
- 类型：feature, refactor
- 关联文件：`src/shared/types.ts`, `src/shared/uiStyle.ts`, `src/renderer/uiStyle.ts`, `src/renderer/components/SettingsTabContent.tsx`, `src/renderer/components/SettingsControls.tsx`, `src/renderer/styles.css`, `src/renderer/vite-env.d.ts`, `src/renderer/mockElectronAPI.ts`, `src/settings/SettingsStore.ts`, `electron/main.ts`, `electron/preload.ts`, `electron/windows/settings.ts`, `index.html`, `settings.html`, `scripts/verify-ui-style-schedule.ts`, `tsconfig.verify.json`, `README.md`

## 变更摘要

- 「外观」分区的界面风格分段控件从设置行尾移到卡片顶部独占一行左对齐，标题与描述在上、控件在下
- 分段控件新增第三档「跟随时间」：按用户自定义的白天时段（默认 07:00–19:00，支持跨零点）在清爽纸面与极光玻璃之间自动切换
- 新增 `src/shared/uiStyle.ts`：白天时段解析与生效风格推导的纯函数，主进程与渲染层共用
- 档位类型拆分为 `UiStyleMode`（aurora / calm / auto）与 `EffectiveUiStyle`（aurora / calm），DOM 上的 `data-ui-style` 只允许生效值
- 渲染层每分钟对齐检查一次生效风格，跨过时段边界即切换；窗口从后台切回时立即纠偏；设置窗与悬浮球同步生效
- 首帧内联脚本按镜像的时段即时算出生效风格，自动档跨时段开窗不再闪一次旧主题
- 设置存储改为逐字段归一化：时段夹到 0–1439，脏档位回落默认

## 影响范围

- 设置项从两档变三档：老配置里的 `aurora` / `calm` 原样合法，无需迁移；新增 `uiStyleDayStartMin` / `uiStyleDayEndMin` 两个字段
- 手动档行为不变；点「极光玻璃 / 清爽纸面」即退出自动模式
- 主进程新增单向 IPC 通道 `effective-ui-style-changed`，只同步设置窗底色，不写盘也不广播 `settings-changed`
- 窗口底色取值统一走 `resolveEffectiveUiStyle`，`#f2f4f8` / `#0b1026` 字面量收敛到 `src/shared/uiStyle.ts` 一处
