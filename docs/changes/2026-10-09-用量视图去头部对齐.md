# 用量视图去头部、与概览对齐

日期：2026-10-09
类型：fix, style, refactor
涉及文件：`src/renderer/components/IncludedUsageTable.tsx`、`src/renderer/styles.css`

## 背景

悬浮球面板在「概览 ⇄ 用量」两个视图间切换时，内容起始线不一致，存在明显的视觉落差：

1. 用量视图顶部有一块 `__header`（`Included Usage` 大标题 + 下方订阅周期日期行），概览视图顶部直接是总览卡；
2. 标题栏 `.floating-ball__panel-header` 的 `margin-bottom: 6px` 原先只用 `:not(.floating-ball__panel--included)` 限定，即**只在概览生效**，用量视图标题栏下方没有这 6px。

两处叠加后，切到用量时内容整体「塌」下去一截，切换瞬间观感断裂。

## 改动

### 1. 组件：不再渲染 `__header`

`IncludedUsageTable.tsx` 移除 `<div className="included-usage__header">`（含 `__title` 与 `__date-range` 两行）。分组块（Cursor / Other）成为滚动区第一个元素，直接顶到内容区上沿。

`display.title` 仍作为 `<section>` 的 `aria-label` 保留，屏幕阅读器可访问的分区名不变；`display.dateRange` 字段保留在 `IncludedUsageDisplay` 数据契约里（本次只是不渲染，未删格式化逻辑），后续若要在概览卡呈现订阅周期可直接取用。

### 2. 样式：标题栏下边距两视图统一

```css
/* 改前：仅概览 */
.floating-ball__panel:not(.floating-ball__panel--included) .floating-ball__panel-header { … }
/* 改后：两视图共用 */
.floating-ball__panel-header { margin-bottom: 6px; font-size: var(--fs-body); }
```

标题栏是两视图共用的 chrome（交通灯 + 品牌名 + 刷新/设置/收起），下边距必须一致。头文件里 `.floating-ball` 原本就有注释 `Shared panel chrome size — overview and included must match.`，本次改动与该意图一致。`font-size` 一并通用化无副作用：`.floating-ball__brand` 与 `.btn-icon` 都有各自的显式字号。

### 3. 清死样式

`__header` 不再渲染后，以下 6 条规则全部失效，已删除（极光与纸面两套都清）：

| 选择器 | 原位置 |
|---|---|
| `.floating-ball__panel--included .included-usage__header` / `__title` | 面板内覆盖 |
| `.included-usage__header` / `__title` / `__date-range` | 基础层 |
| `html[data-ui-style='calm'] .included-usage__title` / `__date-range` | 纸面覆盖 |

## 保留项

- **滚动**：`.included-usage__body` 的 `overflow-y: auto` 与滚动条（极光白色半透明 / 纸面中性灰）原样保留，仅滚动条所在的容器从「第二子元素」变成「第一子元素」，滚动行为不变。
- **402px 配平**：本次只动用量视图，未触碰概览的 `--orb-panel-height: 402px` 配平链（总览卡 + 4 张指标卡 + `metric-list` margin-top 10px / gap 6px）。概览的卡片间距与用量的分组块间距（8px）刻意保持原值——概览间距是配平的一部分，改了会破坏不滚动的精确高度。
- **分区头 / 模型行 / mini 占比条**：`__section-head`、`__entry`、`__entry-share` 及其两套主题样式均未动。

## 验证

- `npm run typecheck` 通过（electron + renderer 两个 tsconfig）。
- `npm run build` 通过；产物 CSS 中 `included-usage__header` / `date-range` 计数为 0，`.floating-ball__panel-header{margin-bottom:6px` 命中 1 条。
- `styles.css` 仍为纯 CRLF（6861/6861），无换行符污染。
