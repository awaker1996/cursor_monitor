# 弹窗概览与用量面板字号统一

- 日期：2026-09-26
- 类型：refactor
- 关联文件：src/renderer/styles.css

## 变更摘要

切换「概览 / 用量」两个视图时，两侧对应的统计元素（区块标签、百分比、Tokens、徽章）字号不一致，给用户带来「两块面板是不同设计」的观感。本次只调样式，不改结构 / 不改数据。

### 对照表

| 元素 | 概览面板（基准） | 用量面板（改前） | 用量面板（改后） |
|---|---|---|---|
| 顶部标题 / Included Usage 标题 | 13px | 12px | **13px** |
| 日期范围 / token 详情 | 11px | 10px | **11px** |
| 区块标签（Cursor Models / 今日 Cursor Models） | 10px | 10px | 10px（保持） |
| 徽章（Cursor / 健康状态 / 来源） | 10px | 9px | **10px** |
| 区块百分比（0.84% / 0.60% 等） | 13px | 10px | **13px** |
| 模型条目的百分比（0.70% 等） | 13px | 10px | **13px** |
| Tokens（461.2万 / 733.0万） | 11px | 9-10px | **11px** |
| 模型名称（auto / composer-2.5） | 10px | 10px | 10px（保持） |

### 调整点

- `included-usage__title` 12px → 13px，与「面板标题」「浮窗头」字号一致
- `included-usage__date-range` 10px → 11px，与「顶部 tokens 详情」字号一致
- `included-usage__badge` 9px → 10px，与「健康状态 / 来源徽章」字号一致
- `included-usage__section-stats .included-usage__entry-tokens` 10px → 11px
- `included-usage__entry-tokens` 9px → 11px
- `included-usage__entry-usage` 10px → 13px，并加粗到 700，与概览卡片百分比同等级
- 其余位置（区块标签、模型名称）原本就和概览对齐，保持不动

## 影响范围

- 仅悬浮球弹窗切换「概览 / 用量」时的视觉对齐度
- 不改数据、不改结构、不改交互、不改窗口尺寸

## 验证

- `npm run typecheck`
- 弹窗展开后切换两个 Tab：标题字号、百分比字号、Tokens 字号一致；徽章、标签、模型名字号一致
- 两个 Tab 的视觉密度对齐，再切换不出现「同一面板两种字号体系」的割裂感
