# 清爽纸面主题视觉丰富化

## 日期
2026-10-06

## 类型
feature, refactor

## 关联文件
- `src/renderer/styles.css`

## 变更摘要

- 页面底色：纯平面色升级为三层静态「坐标纸」画布——右上冷色天光 + 左下暖绿环境光 + 22px 方格点阵；导航与顶栏半透明白让点阵微透
- 卡片：白卡微渐变 + 双层纸影 + 顶部「染色纸」晕染与顶边框着色（后经统一化调整为全卡同色，见「设置卡片风格统一与外观页等高」）
- 导航：激活项渐变底 + 左侧渐变索引条 + 图标白瓷芯片；标题栏恢复静态低饱和品牌渐变缝线；页头 h1 墨色→深蓝渐变字；面板标题加渐变引导条
- 控件：开关开启态渐变 + 内高光、关闭态凹槽；主按钮 / 分段选中项 / 次级按钮统一渐变与顶部内高光；输入框内阴影
- 数据可视化：全部进度条（总消耗 / 今日 / 周期 / 限额 chip / 订阅计量条）渐变填充，轨道加凹槽阴影；今日卡淡蓝渐变；订阅表格表头着色 + 斑马纹 + 悬停行
- 胶囊 / 徽章贴纸式内高光；悬浮球改白瓷渐变球体 + 静态健康色光环（随绿/黄/蓝/灰健康态变色）；数据面板头部压品牌渐变缝线
- 全部读数统一 `font-variant-numeric: tabular-nums` 等宽对齐
- 修复 calm 层 `.sub-meter__seg` 覆盖优先级把订阅计量条彩色分段压灰的问题（补齐 ok/warn/bad 状态渐变）
- Toast 改墨色微渐变，保留通知分量感

## 影响范围

- 仅 `html[data-ui-style='calm']` 覆盖层，全程静态、无新增动效，Aurora 主题零改动
