# 弹窗顶部去灯盒加 Cursor 监控

- 日期：2026-09-27
- 类型：refactor
- 关联文件：src/renderer/App.tsx、src/renderer/styles.css

## 变更摘要

紧接 `2026-09-26-弹窗顶部红黄绿灯动画` 之后，按反馈调整弹窗 header 左侧组合：去掉包裹三色圆点的灯箱外壳，仅保留三盏灯与其呼吸动画，并在其后追加 "Cursor监控" 品牌文案。

> 第二轮调整（同一任务内）：首版 "Cursor监控" 用 13px / 600 / `#e0e0e0` 渲染后反馈"与周围元素不协调"——因其字重与亮度高于 `dashboard-summary__label`、与下方数值同级，挤占了数据层级。改为 12px / 500 / `#cbd5e1`，降为"次级文案"，与面板 label 同档。

### 灯箱外壳（`.traffic-lights`）移除

- 删除 `padding: 5px 11px`
- 删除背景叠加 `background: rgba(255, 255, 255, 0.03)`
- 删除极淡描边 `border: 1px solid rgba(255, 255, 255, 0.07)`
- 删除圆角 `border-radius: 9px`
- 删除凹陷阴影 `box-shadow: inset 0 1px 0 ..., inset 0 -1px 0 ...`
- **保留** `display: inline-flex; align-items: center; gap: 7px;`，让三盏灯继续作为内联排布容器

### 新增品牌组合

- 新增 `.floating-ball__brand-row`：header 左侧的 inline-flex 容器，承载 `<TrafficLights />` + "Cursor监控" 文案
- 新增 `.floating-ball__brand`：`font-size: 12px; font-weight: 500; color: #cbd5e1; letter-spacing: 0.2px; white-space: nowrap;`，刻意做成"次级文案"调性，与 `dashboard-summary__label`（12px / 500 / `#9ca3af`）同一档，比数值 `#f3f4f6` 暗一档，避免抢数据层级
- "Cursor监控" 仅作品牌展示，不携带任何数据状态含义
- 文案为中文（无英文），符合项目文案规范
- brand-row 内三灯 ↔ 文案间距由 10px 微调到 12px，让动画圆点与文字之间有更舒展的呼吸感

### App.tsx 结构变化

- header 左侧由单元素 `<TrafficLights />` 改为 `<div className="floating-ball__brand-row"><TrafficLights /><span className="floating-ball__brand">Cursor监控</span></div>`
- `<TrafficLights />` 内部保持不变（仍渲染三盏灯 + `role="status"` + `aria-label="状态指示灯"`）
- 右侧 `floating-ball__header-actions`（刷新/设置/收起）位置不变

## 交互细节

- 三盏灯之间的错相位动画节奏不变：2.7s 周期，红 0s → 黄 0.9s → 绿 1.8s
- 三盏灯呼吸曲线不变：熄灭 0% → 微亮 10% → 峰值 18% → 微亮 28% → 熄灭 100%
- 灯罩玻璃质感 + 外发光 + `transform: scale(1.05)` 峰值放大均不变
- `prefers-reduced-motion: reduce` 下三灯静态显示熄灭态 `#16162b`，行为不变
- header 拖拽手柄（`floating-ball__drag-handle`）作用域不变，整条左侧品牌行仍可拖拽

## 可访问性

- "Cursor监控" 为装饰性品牌文案，未设独立 `aria-label`
- 三盏灯的可访问性标签 `role="status"` + `aria-label="状态指示灯"` 保持原状

## 影响范围

- 仅影响悬浮球弹窗顶部 header 左侧布局
- 不改数据流、不改刷新/设置/收起按钮、不改拖拽行为
- 不影响 `health-pill`、悬浮球环颜色等其他视觉状态指示
