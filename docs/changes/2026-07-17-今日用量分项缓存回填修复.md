# 今日用量分项缓存回填修复

- 日期：2026-07-17
- 类型：fix
- 关联文件：src/core/snapshotMerge.ts、scripts/verify-today-percent.ts

## 变更摘要

- 今日 API 与 First-party 指标改为逐字段判断并回填缓存，避免其中一项刷新成功时阻止另一项回填
- 仅在实际采用缓存值时标记快照为缓存数据
- 增加部分刷新场景回归检查，验证新鲜 API 数据保留且 First-party 百分比与 token 可从缓存恢复

## 影响范围

- 同一自然日、同一计费周期内，今日 First-party 或 API 指标偶发无法计算时不再显示 `--`
- 跨自然日或计费周期变化时仍不会沿用旧缓存

## 验证

- `npm run typecheck`
- 通过项目内置 esbuild 打包并执行 `scripts/verify-today-percent.ts`，全部回归断言通过
