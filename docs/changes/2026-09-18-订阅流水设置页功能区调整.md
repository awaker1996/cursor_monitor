## 变更摘要

### 1. Tab 顺序调整
- Tab 顺序改为：订阅 → 流水 → 其他（原"设置"）
- 默认打开 Tab 改为"订阅"

### 2. 订阅 Tab 补充 Cursor 平台
- 新增 `CursorProvider`，复用 `ProviderManager` 的 `TokenSnapshot` 构建订阅数据
- 展示周期内 Cursor Models 和 Other Models 的用量百分比及模型明细
- 原"设置"页的"凭据与连接"（Cookie 配置 + 测试连接）移到订阅 Tab 的 Cursor 分区下
- `SubscriptionManager` 构造函数新增 `getSnapshot` 参数以获取 Cursor 快照

### 3. 流水按平台筛选
- `UsageFlowQuery` 新增 `platform` 字段，支持 `cursor` / `deepseek` 两个平台
- `ProviderManager.fetchUsageFlow` 按 platform 分发，新增 `fetchDeepSeekUsageFlow` 方法
- DeepSeek 流水通过 `/api/v0/usage/amount` 接口获取按天按模型明细，转换为流水条目
- `FlowPage` 新增平台切换按钮组

### 4. 流水手动刷新
- 去除进入流水页时的自动加载（原 `useEffect` 自动调用 `loadFlow`）
- 改为手动点击"刷新"按钮加载数据
- 切换平台时不自动刷新，清空当前数据

### 5. 订阅自动刷新取设置页配置
- 去除硬编码的 3 分钟自动刷新
- 改为读取 `AppSettings.autoRefreshEnabled` 和 `AppSettings.refreshIntervalSec`
- 设置页"数据刷新"配置变更即时生效于订阅页

## 影响范围
- 设置窗口的三个 Tab 页面布局和功能
- 订阅页 Cursor 分区数据展示
- 流水页平台筛选交互
- `SubscriptionManager` 构造签名变更（新增第三个参数）
- `ProviderManager.fetchUsageFlow` 新增平台路由逻辑

## 验证
- 启动应用，打开设置窗口，确认 Tab 顺序为"订阅、流水、其他"
- 订阅页 Cursor 分区展示周期用量百分比和模型明细
- 订阅页 Cursor 凭据配置区域可保存/清除 Cookie 和测试连接
- 流水页不自动加载，点击"刷新"后加载数据
- 流水页可切换 Cursor / DeepSeek 平台
- 订阅页自动刷新跟随设置页"数据刷新"配置
