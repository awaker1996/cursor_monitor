# 外观：跟随系统主题与界面风格卡重排

- 日期：2026-10-25
- 类型：feature, refactor, style
- 关联文件：`src/shared/types.ts`, `src/shared/uiStyle.ts`, `src/settings/SettingsStore.ts`, `src/renderer/uiStyle.ts`, `src/renderer/components/SettingsControls.tsx`, `src/renderer/components/SettingsTabContent.tsx`, `src/renderer/styles.css`, `electron/main.ts`, `electron/windows/settings.ts`, `index.html`, `settings.html`, `scripts/verify-ui-style-schedule.ts`, `README.md`

## 变更摘要

- 界面风格新增**「跟随系统」**档：随 Windows 深色 / 浅色设置切换（系统深色 → 极光玻璃，系统浅色 → 清爽纸面），系统换主题即时生效
- 切换按钮重排为两组、四档：**自动跟随**（跟随系统 / 跟随时间）｜**手动固定**（清爽纸面 / 极光玻璃）；分段控件等宽撑满卡片，两组之间一道细分隔线
- 风格卡布局按使用习惯重排：标题 + 「当前生效」胶囊同一行 → 档位说明 → 分段控件 → 作用范围注脚 →（仅自动时段档）弱化的时段子区
- 时段设置整体弱化：缩进、左侧细线、低对比小字与浅底，不再抢风格切换的视觉焦点
- 时间选择器由原生 `time` 输入改为「时 : 分」两个下拉：点开即列表，不再弹系统时钟；分钟按 5 分钟一档，已存的非整 5 分钟值（如 07:03）单独保留一项，不会被悄悄改掉
- 文案重写：四档描述、状态胶囊（含「系统深色 / 系统浅色」与「07:00–19:00」附注）、时段子区、切换 toast
- 首帧内联脚本按 `ui-style-mode` 区分手动档 / 时段档 / 跟随系统，跟随系统用 `prefers-color-scheme` 即时上色，冷启动不闪主题
- 主进程建窗与改设置时按 `nativeTheme.shouldUseDarkColors` 解析底色，并监听 `nativeTheme` 的 `updated` 事件同步设置窗背景

## 影响范围

- `UiStyleMode` 增加 `'system'`；`SettingsStore.normalize` 接受该值，老配置（aurora / calm / auto）无需迁移，默认档位仍是 aurora
- `resolveEffectiveUiStyle(mode, startMin, endMin, systemPrefersDark, now?)` 增加**必填**的 `systemPrefersDark` 参数，所有调用点显式传入（主进程取 `nativeTheme`，渲染层取 `prefers-color-scheme`），漏传会编译失败
- `UI_STYLE_OPTIONS` 增加 `group`（auto / manual）并重排顺序；新增 `UI_STYLE_LABELS`、`UI_STYLE_MODE_STORAGE_KEY`、`systemPrefersDark` / `useSystemPrefersDark`
- 渲染层 `useUiStyleSync` 新增 `prefers-color-scheme` 变化监听；原有按分钟对齐的时段检查保持不变
- `TimeRangeInput` → `TimeRangeSelect`（去掉编辑期的 `onFocus` / `onBlur`：下拉是原子提交，不再有半截输入）；`Segmented` 增加 `wide` 与 `group` 分组分隔线
- DOM 不变量不变：`data-ui-style` 仍只有 `aurora` / `calm`
