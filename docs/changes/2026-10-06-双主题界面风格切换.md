## 变更摘要

- 新增 `UiStyle` 设置项（`aurora` 深色玻璃极光 / `calm` 浅色清爽纸面），默认 `aurora`；设置页「外观」分区提供 Segmented 切换，改动即时保存并经 `onSettingsChanged` 广播
- 新增 `src/renderer/uiStyle.ts`：`UI_STYLE_OPTIONS` 风格元数据、`applyUiStyle` 写 `<html data-ui-style>`、`useUiStyleSync` 供悬浮球 App 与设置页双入口启动时应用并持续跟随
- `styles.css` 新增清爽纸面主题覆盖层：全部规则加 `html[data-ui-style='calm']` 前缀（特异性必然覆盖），Aurora 基底不受影响
- Electron 侧窗口底色跟随风格：创建设置窗时按 `uiStyle` 取 `#f2f4f8` / `#0b1026`，`updateSettings` 收到 `uiStyle` 变更时同步 `setBackgroundColor`，避免加载与拉伸窗口时深浅色闪变
- 纯浏览器 dev 预览支持：`main.tsx` 接入 `installBrowserMock`，mock 补充悬浮球示例快照（DEMO_SNAPSHOT）与 `uiStyle` 默认值
- README 设置项表补充 `uiStyle` 行

## 影响范围

- 两窗（悬浮球 / 设置窗口）整体视觉风格；设置项结构新增一个键（旧配置文件缺省时由 DEFAULT_SETTINGS 兜底为 aurora）
- 不改数据链路与订阅查询逻辑

## 验证

- `npm run typecheck` 通过
- 浏览器 dev 预览（/settings.html、/index.html）切换 `data-ui-style` 即时生效，Aurora 基底视觉无回归
