## 变更摘要

- 菜单合并：「外观」「悬浮球」「应用图标」三个入口合并为一个「外观」面板（界面风格 + 贴边自动收起 + 应用图标三卡纵排，各自保留分区描述语义）；`SettingsSectionId` 收敛为 accounts / data / appearance / about
- 菜单标签统一两字（账户 / 数据 / 外观 / 关于），长度完全一致；完整语义保留在右侧面板大标题（「账户与订阅」「数据刷新」）
- 导航列宽 168px → 148px，两字标签下整列更紧凑，主区增加可用宽度
- 导航底部新增品牌角标（logo + Cursor Monitor + v1.0.0，版本号经 `resolveJsonModule` 读取 `package.json`）：导航改纵向 flex，角标 `margin-top: auto` 沉底，上下两端锚定后中段留白呈呼吸感而非空缺
- 窄屏（≤640px）横排导航断点下角标自动隐藏
- 关于页功能清单中引用旧导航结构的文案同步更新

## 影响范围

- 设置窗口导航结构（6 项 → 4 项）与面板组织；不改任何设置项的存储与行为
