## 变更摘要

- 问题：Cursor 卡片收起态的「今日 Cursor / 今日 Other」两根用量小条在当前数据下整体消失，卡片标题与状态 pill 之间留白。根因是数据口径而非渲染：今日百分比由 normalizer 在 Cookie 聚合事件完整时才计算，官方额度源（OfficialProvider）或今日事件不完整时 `autoTodayUsedPercent / apiTodayUsedPercent` 为 null，而 f09d170 的设计是「缺今日数据不出小条」，于是整个小条区消失
- 修复：`cursorCollapsedChips` 增加窗口回退——今日口径任一存在时照旧出「今日 Cursor / 今日 Other」；否则回退为周期口径（`cursorModelsUsedPercent / otherModelsUsedPercent`），标签明确标注「周期 Cursor / 周期 Other」，悬停提示为「周期 Cursor Models已用 X%」，不冒充今日数据；今日与周期都缺失（无任何可用数据）时才不出小条
- 收起态小条分组无障碍名称由「今日用量摘要」改为「用量摘要」（口径窗口可变）
- `scripts/verify-collapsed-usage.ts` 断言更新：新增周期回退（标签 / 百分比 / tooltip）与双缺失不出小条两组用例
- README 两处收起态描述同步：补充 Cursor 用量小条及其今日→周期回退说明，并顺带补上 Command Code 每月限额小条的表述

## 影响范围
