# 设置卡片风格统一与外观页等高

## 日期
2026-10-06

## 类型
refactor

## 关联文件
- `src/renderer/styles.css`

## 变更摘要

- Aurora：删除按分区变化的卡片流光色相（data 蓝 / ball 绿 / icon 橙 / about 紫 / appearance 靛五组 `--glow-*` 覆盖），所有卡片共享同一套品牌四色流光边框
- 清爽纸面：删除按分区变化的卡片染色晕染与顶边框色，统一为中性冷灰「染色纸」；分区身份改由导航与页面标题承担，卡片回归同一种构件
- 外观页三张单行卡等高：实测自然高度 92.5 / 73.9 / 91.3px，统一 `min-height: 94px` + 卡体纵向 flex 居中，内容不足的卡上下留白对称；用 min-height 而非固定 height，窗口收窄描述多折一行时卡片仍可自动长高不裁切
- 等高规则以 `#settings-panel-appearance` 限定作用域，不影响数据刷新多行卡片与关于页铺满卡

## 影响范围

- 设置页全部卡片的视觉一致性；不改组件结构与设置行为

## 验证

- `npm run typecheck` 通过
- 浏览器 dev 预览两主题外观页：三卡同色同高（实测 94/94/94），Aurora 流光统一
