# 缓存报错与收起闪烁修复

- 日期：2026-07-06
- 类型：fix, feature
- 关联文件：electron/main.ts、electron/preload.ts、electron/windows/floatingBall.ts、src/renderer/App.tsx、src/renderer/styles.css、src/renderer/vite-env.d.ts

## 变更摘要

- 补全 Chromium 缓存路径：新增 `app.setPath('cache')`，dev 环境禁用 GPU shader / HTTP 磁盘缓存，旧缓存目录不可写时记录 warning
- 新增 `setOrbModeAsync` IPC，供 dock/hover 等场景兼容
- 折叠态移除独立 health-dot，改为圆环进度端点 cap（QQ 管家轻量风格）
- `.floating-ball` 增加 `overflow: hidden`，避免光晕在窗口边界形成方形残影
- **根治收起闪烁**：悬浮球窗口固定为展开尺寸 300×448，展开/收起仅切换 React 状态与 CSS，不再 `setBounds` 缩放
- 新增 `setIgnoreMouseEvents` IPC，折叠态透明区域鼠标穿透，orb/面板区域保持可交互
- 修复鼠标穿透导致 orb 无法点击：展开态强制关闭穿透，折叠态默认可点击、仅在光标位于透明区域时启用穿透
- 修复贴边 undock 后窗口恢复为 80×80 导致无法展开明细：undock 时恢复贴边前完整窗口位置
- 贴边/undock 不再缩放窗口（固定 300×448），仅 reposition，消除拖出时桌面闪烁
- 明细面板移除 `backdrop-filter`，改为纯色半透明背景，避免透明窗口下方块残影
- 明细面板保留 60ms opacity 渐入动画
- 圆环端点角度改为与 `-90deg` 起点一致，并恢复进度环 round 线帽，消除端点错位导致的断点感

## 影响范围

- dev 启动 stderr 显著减少，功能不受影响
- 展开/收起、拖拽、贴边交互保持原样；贴边 peek 与展开面板健康指示不变
- 折叠态窗口物理尺寸为 300×448，透明区域点击穿透至下层应用

## 验证

- `npm run typecheck` 通过
- 展开后点击悬浮球收起无矩形包裹闪烁
- 折叠态点击悬浮球展开无矩形包裹闪烁
- 折叠态透明区域可点击穿透
- orb 拖拽、hover、点击正常
- 贴边 / undock 后交互正常
- 折叠态圆环与端点 cap 视觉统一，无右上角双绿点冲突
