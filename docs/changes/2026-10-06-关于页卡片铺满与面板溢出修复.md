# 关于页卡片铺满与面板溢出修复

## 日期
2026-10-06

## 类型
feature, fix

## 关联文件
- `src/renderer/components/SettingsPanel.tsx`
- `src/renderer/pages/SettingsPage.tsx`
- `src/renderer/styles.css`

## 变更摘要

- `SettingsPanel` 新增 `fill` 属性（关于页启用）：面板 `min-height: 100%` 纵向 flex，卡片与卡体逐层伸展到面板区底部，12 条功能列表 `space-evenly` 在剩余高度均匀铺开，底部不再大片空白
- 用 min-height 而非固定 height：窗口更小时内容超高自动回退为纵向滚动
- 顺带修复 Aurora 下面板区一直存在的横向滚动条：卡片流光光斑伪元素（`inset: -30%`）超出卡片边界撑宽滚动区，`.settings-page__panels` 补 `overflow-x: hidden` 裁掉，两主题均不再出现横向滚动

## 影响范围

- 关于页布局；面板区溢出裁剪对全部分区生效（仅裁掉装饰性溢出，无内容截断）

## 验证

- `npm run typecheck` 通过
- 浏览器 dev 预览（840×700 视口，默认窗口尺寸）：关于页卡片贴底无空白、功能条目均匀分布；横向滚动条消除（scrollWidth 复核）
