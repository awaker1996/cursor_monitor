# 流水独立刷新与日期分页

- 日期：2026-07-22
- 类型：feature
- 关联文件：src/renderer/pages/FlowPage.tsx、src/renderer/components/UsageFlowFilters.tsx、src/renderer/components/UsageFlowPagination.tsx、src/shared/usageFlowDates.ts、src/core/providers/CookieProvider.ts、src/core/providers/ProviderManager.ts、electron/main.ts、electron/preload.ts、src/shared/types.ts、src/core/normalizer.ts

## 变更摘要

- 用量流水窗口不再订阅 poller 快照自动刷新，改为独立 `fetch-usage-flow` IPC 手动拉取
- 新增日期快捷筛选（1d / 7d / 30d / MTD / Last month）与自定义日期范围
- 列表支持服务端分页（每页 100 条，上一页/下一页）
- 从 `TokenSnapshot` 移除 `usageFlow` 字段，避免快照缓存膨胀

## 影响范围

- 流水窗口打开后需点击「刷新」或切换筛选/分页才会更新数据
- 悬浮球与托盘轮询行为不变

## 验证

- 流水窗不随悬浮球自动刷新变化
- 切换 1d/7d 等预设后重新拉取对应区间数据
- 自定义日期范围生效，Date 列仍为东八区
- 分页切换请求不同 page，显示总条数与页码
