# 悬浮球贴边消失与托盘重置

- 日期：2026-07-24
- 类型：fix, feature
- 关联文件：electron/floatingBallDock.ts、electron/windows/floatingBall.ts、electron/main.ts、electron/tray.ts、src/renderer/App.tsx、README.md、requirements.md

## 变更摘要

- 贴边定位时窗口向屏外扩展 `ORB_DOCK_HIDE_OFFSET`，半隐球体仍落在 HWND 内，避免 Windows 无法点击窗外像素
- 角落双边缘同时满足阈值且距离差 ≤ 8px 时优先吸附 left/right，减少右下贴底难以拖出
- `get-cursor-in-window` 光标不在内容区时返回 null；贴边态关闭鼠标穿透，避免 peek 条点不中
- 托盘菜单：查看流水、应用设置、重置悬浮、退出；「重置悬浮」显示窗口、清除贴边并回到主屏默认右下角
- 抽取 `getDefaultFloatingBallBounds()` 供创建与重置共用

## 影响范围

- 四边贴边交互与命中
- 系统托盘右键菜单文案与恢复入口

## 验证

- `npm run typecheck`
- 拖到右下及四边：半隐可 hover、点击 undock、向内拖出
- 托盘「重置悬浮」：隐藏或贴边后恢复至主屏右下未贴边态
