# 设置页「其他」Tab 三列网格与核心功能卡

## 日期
2026-09-20

## 类型
feature, refactor

## 关联文件
- `src/renderer/components/SettingsTabContent.tsx` — 根容器加 `page-shell--settings` 修饰类；挂载核心功能卡
- `src/renderer/components/ProjectFeaturesCard.tsx`（新增）— 从 README 抽取核心功能并渲染
- `src/renderer/styles.css` — Tab 样式精修、三列网格布局、核心功能卡样式、窄窗回退

## 变更摘要

### Tab 切换样式精修
1. Tab 文字左边缘对齐到内容区 32px（原先 Tab 自身内缩 20px，与下方卡片左边缘错位）
2. 新增 hover 浅灰圆角胶囊背景；激活项保持深色文字 + 2px 蓝线（上移贴合分隔线），hover 时改用淡蓝底以区分
3. `focus-visible` 轮廓随新的 8px 圆角调整 `outline-offset`
4. 键盘可达性不变（`role="tablist"` / `role="tab"` / `aria-selected`）

### 「其他」Tab 由单列改为三列网格
1. `.page-shell--settings` 由 flex column 改为 grid：`repeat(3, minmax(0, 1fr))` + `grid-template-rows: auto minmax(160px, 1fr)`
2. 三张设置卡（数据刷新 / 悬浮球 / 外观）同处一行并自动等高；核心功能卡跨三列、吃掉剩余高度，页面底部不再留空白
3. 跨列职责从外观卡转移到核心功能卡（外观卡不再使用 `settings-section--wide`）
4. 响应式三档：≥940px 三列 / ≤940px 两列 / ≤720px 单列；各断点显式给出行模板，保证最后一行仍能撑满
5. 附带收益：刷新间隔输入框由原来横贯整屏（约 1010px）收敛到约 300px

### 核心功能卡（内容来自 README.md）
1. 新增 `ProjectFeaturesCard`，通过 `import readmeSource from '../../../README.md?raw'` 在构建期内联 README，**不复制粘贴内容**，README 改动即同步
2. 提取两段：开头 blockquote 作为一句话简介；`**范围内：**` 到 `**范围外：**` 之间的 10 条 bullet 作为功能清单
3. 内含极简行内渲染（`**粗体**` → `<strong>`、`` `code` `` → `<code>`），不引入 markdown 依赖
4. 卡片占满整行剩余高度，内部 `.project-features` 为独立滚动区（`flex: 1; min-height: 0; overflow-y: auto`），内容超出时卡内滚动，不撑高整页

## 影响范围
- 仅影响设置窗口「其他」Tab，「订阅」「流水」Tab 未改动
- 设置窗口默认 1120×720：三列生效；窗口最小宽 800px 时落在两列档
- README.md 成为设置页内容来源之一：其开头简介与「范围内」清单会直接反映到界面
- 卡片高度依赖容器高度确定（见下方修复项），窄窗口下仍可整页滚动兜底

## 验证
- `npx tsc -p tsconfig.json --noEmit` 通过（确认 `?raw` 类型声明可用）
- 用临时壳页（注入 `electronAPI` mock）+ headless Chrome 在真实窗口尺寸（1118×689 视口）截图核对：

- 修复项复验：
