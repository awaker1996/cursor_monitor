# 界面风格：跟随系统 + 卡片布局重排

- 日期：2026-10-25
- 状态：已实现

## 背景

设置页「外观 → 界面风格」只有「极光玻璃 / 清爽纸面 / 跟随时间」三档，缺少最常见的「跟随系统」；分段控件排成一条、手动档排在自动档前面，与使用习惯不符；「跟随时间」展开的时段行仍是整行高亮的设置行，视觉权重过高；原生 `time` 输入点开是系统时钟弹窗，改一个小时内要拖两下，别扭。

目标四点：

1. 新增「跟随系统」档，随 Windows 深浅色即时切换；
2. 重排按钮顺序：自动跟随（跟随系统 / 跟随时间）在前，手动固定（清爽纸面 / 极光玻璃）在后，组间加分隔线；
3. 弱化时段设置：缩进子区 + 左侧细线 + 低对比小字；时间选择改为「时 : 分」下拉；
4. 卡片布局按「先看状态、再换风格、最后设细节」重排，并重写文案。

## 数据结构

```ts
export type UiStyleMode = 'system' | 'aurora' | 'calm' | 'auto';
```

`resolveEffectiveUiStyle` 增加必填参数 `systemPrefersDark`：

```ts
resolveEffectiveUiStyle(mode, startMin, endMin, systemPrefersDark, now = new Date())
//  system → systemPrefersDark ? aurora : calm
//  auto   → 白天时段内 calm，其余 aurora
//  手动档 → 原样返回
```

必填而非可选：跟随系统依赖外部环境值，可选参数会让漏传静默退化成「永远浅色」。
