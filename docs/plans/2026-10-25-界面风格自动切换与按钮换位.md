# 界面风格：切换按钮换位 + 按时间自动切换

- 日期：2026-10-25
- 状态：已实现

## 背景

设置页「外观」分区的「界面风格」卡片把「极光玻璃 / 清爽纸面」分段控件放在设置行最右端，离标题/描述很远；主题也只有手动二选一，白天护眼浅色与夜间深色要手动来回点。

目标两点：

1. 分段控件挪到**卡片顶部独占一行左对齐**（标题与描述下方），让"选风格"成为这张卡的第一视觉焦点；
2. 新增**「跟随时间」第三档**：用户给定白天时段（默认 07:00–19:00，可自定义、允许跨零点），白天用清爽纸面、夜间用极光玻璃，到点自动切换，悬浮球与设置窗口同时生效。

## 数据结构

`src/shared/types.ts`：

```ts
export type UiStyleMode = 'aurora' | 'calm' | 'auto';   // 用户选择的档位
export type EffectiveUiStyle = 'aurora' | 'calm';        // 实际生效值（DOM 上只允许这两个）

interface AppSettings {
  uiStyle: UiStyleMode;        // 原 uiStyle 字段改类型
  uiStyleDayStartMin: number;  // 白天时段起点（自 00:00 起的分钟数），默认 420
  uiStyleDayEndMin: number;    // 白天时段终点，默认 1140
}
```

档位与生效值分开的原因：`data-ui-style` 若被写成 `'auto'`，calm 覆盖层会整体失效且 TypeScript 不报错；收窄成 `EffectiveUiStyle` 后误传即编译失败。派生值不落盘，自动模式下不会每分钟写盘。

## 关键设计

- **调度在渲染层**：两个渲染入口（悬浮球 / 设置窗）共用 `useUiStyleSync`，每分钟对齐检查一次生效风格是否变化；主进程不跑定时器。窗口从后台切回（`visibilitychange` / `focus`）时立即纠偏。
- **退出自动**：点「极光玻璃 / 清爽纸面」即写入档位，自动自然失效——档位是唯一真源，没有额外开关。
- **边界语义**：白天时段左闭右开 `[start, end)`；`start > end` 视为跨零点（`[start,24:00) ∪ [00:00,end)`）；起止相同为空窗口，UI 禁止提交并提示。
- **首帧防闪**：`localStorage` 镜像生效值（`ui-style`）与自动档时段（`ui-style-auto`）；两页内联脚本按当前时间即时算出生效风格，避免跨时段开窗闪一次旧主题。
- **不变量**：`data-ui-style` 永远只有 `'aurora' | 'calm'`，`'auto'` 只存在于设置层。
